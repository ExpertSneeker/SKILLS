# 拍摄图预处理

## 固定路径与术语

- 当前任务根目录下的输出目录固定为 `3000px拍摄图`，映射文件固定为 `3000px拍摄图/_manifest.json`。
- “原始拍摄图”只指预处理源目录中的文件，仅允许本模块脚本读取；不得执行 `view_image`，不得提供给主 Agent、Subagent 或当前生图工具。
- 本 Skill 后文的“产品实拍图”“产品实拍”“实拍输入”和“产品垫图”均指映射文件中登记的 `3000px拍摄图` 目标文件。
- VI、版式参考图、面料色卡、需求表嵌入图和共享结构素材不属于本模块的原始拍摄图。

## 执行

读取需求表并确认任务根目录后，首次 `view_image`、提示词规划、Agent 分发或生图前运行：

```powershell
python <temu-img-skill-dir>\scripts\prepare_product_photos.py --task-root <任务根目录绝对路径> [--source <原始拍摄图目录绝对路径>]
```

- 未传 `--source` 时，脚本只解析任务根目录下固定名称 `产品拍摄原图.lnk`，不扫描任务根目录寻找拍摄图。
- 仅递归处理源目录中的 JPG/JPEG/PNG；RAW、XMP、DB 等其他格式只按扩展名跳过，不打开、不复制、不转码。
- 目标保留源相对子目录和原文件名。长边不大于 3000px 时原样复制；超过时修正 EXIF 方向并等比缩放至 3000px。
- 映射是后续可用产品实拍输入的唯一清单。多 Session 重跑时复用未变化文件，只补充新增、变化、缺失或损坏的目标。

脚本返回非零、映射缺失、映射为空或检测到另一个预处理任务正在运行时立即阻塞。等待已有任务结束或修复素材后重跑；不得绕过脚本直接使用原始拍摄图。
