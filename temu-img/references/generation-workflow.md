# 通用生成流程

## Agent 职责

**主 Agent**

- 读取需求表，拆分整套图片任务，统一风格、配色、字体、尺寸规范和输出顺序。
- 输出每张图的用途、文案、卖点和参考图清单。
- 为每个图号建立独立任务链；每条任务链在首次派发前冻结本图号的三版提示词、产品基准、准确输入路径和目标文件名。
- 任一任务链完成当前 direct 的来源登记并取得独立验收 `PASS` 后立即推进本链下一版，不等待其他图号；`FAIL` 只替换当前链的当前 direct，其他任务链继续。
- 主 Agent 只负责统筹和调度，不直接生成任何图号。
- 本文件只限制同时调用生图工具的单版生成 Subagent，最大并发数为 `3`；验收、素材读取和其他非生成 Subagent 不计入此上限，也不受本文件额外限制。图号内 Direct 串行、Direct 隔离、单次调用和失败换新 Session 契约适用于所有生图适配器；适配器只能增加约束，不得放宽，冲突时以本文件为准。
- 主 Agent 必须持续派发、等待并补充单版生成 Subagent 与独立验收 Subagent，直至待办清零；待办非空或终验未通过时禁止输出 `final`。

**单版生成 Subagent**

- 主 Agent 在派发前锁定当前图号的共同产品基准、准确输入路径和 `direct01`、`direct02`、`direct03` 三版提示词。
- 每个 direct 使用一个全新单版生成 Subagent；一个 Subagent 只对应一个 direct、只调用一次当前生图工具，完成来源登记后退出。
- 同一图号的三个单版生成 Subagent 必须串行执行；当前 direct 未经独立验收取得 `PASS` 前，不得派发下一版。
- 单版生成 Subagent 只接收当前 direct 的冻结提示词、产品基准、准确输入路径和目标文件名；不得读取、引用或继承其他 direct。
- 结束后把最终提示词、参考图角色、完整来源记录和唯一输出路径回写主 Agent；使用共享来源清单时，单版生成 Subagent 不得自行写入。

## view_image 与图片角色

- 所有参与生图的图片必须先执行 `view_image`；未执行的图片不得声称已提供给模型。
- 产品实拍输入只允许使用 `2560px拍摄图/_manifest.json` 登记的目标文件；原始拍摄图禁止执行 `view_image`，也不得出现在输入角色中。
- 每个单版生成 Subagent 必须在自己的全新上下文中重新执行 `view_image`，并记录每张输入图的角色：
  - Image 1 = edit target / base image
  - Image 2 = primary product identity reference
  - Image 3 = fabric/material reference
  - Image 4 = detail reference
  - Image 5 = layout reference
  - Image 6 = style reference
  - Image 7 = scene reference
  - Image 8 = insert/supporting asset
- 根据当前 direct 实际使用的输入记录角色，不沿用上一版或其他 Session 的图片编号与上下文。

## 产品与参考基准

- 首次生图前建立产品/面料基准：指定强制产品/面料输入，记录必须保持的颜色、纹理、结构、比例、售卖数量(没要求多PC则默认为单个售卖)和载体适配；定制产品还须记录默认系带数量与位置、滚边数量、参考素材。
- 映射中的产品实拍图必须作为强制产品输入垫图。场景或版式与实拍颜色冲突时，以映射中的产品/面料实拍图为准，并在提示词中写明禁止偏离项。
- 参考图只用于风格、氛围和信息组织版式，不得照搬他店人物、产品、文案、图标或品牌元素。
- 本文件夹或需求表中有关键 JPG 参考图时，可选择与当前卖点最相关的图片作为附加参考。
- 提示词必须写明“保留产品结构、面料、颜色和比例，不重设计产品”。
- 每版提示词和失败补生成提示词都必须重复主产品身份参考及产品不可变项，只允许改变当前版本明确指定的场景、构图和版式；除明确修改项外，其余保持不变。
- 提示词不得用文字重新定义产品外观；不要描述颜色、细节、结构、面料纹理、缝线、厚度或形状，只用“参考图 N 中的 XX”指代产品。

## 生成与恢复

- 使用整张直接图生图生成图片，包括图中的英文文字。除当前生图工具外，其他工具只可用于素材读取或转码、临时检查对比、尺寸调整和文件保存，不得替代图生图制作最终设计。
- 产品、面料、纹理、结构或颜色需要实拍支撑时，只能从映射中选择相应的单张或多张产品图作为输入，禁止文生图凭空生成产品。
- 不得改变产品细节、结构、面料、颜色或比例。
- 场景图中的产品必须符合真实尺寸。用人物、家具、床、椅子、宠物、儿童或使用环境校验，不得过大或过小；固定尺寸须选择匹配载体，连续定制尺寸须按载体完整可用区域生成匹配成品，且不得留空或溢出；坐垫用于沙发时须替换原有座垫。堆叠主图使用载体时，坐垫必须与完整可用座面四边齐平，不得露出座面或溢出。
- `N PC` 商品在同一使用场景中必须准确展示 `N` 件产品，数量未知时不得推断；同时存在多颜色与多个 PC SKU 时，每个 PC 规格必须使用独立 SKU 图号且全部使用设计模块选定的统一颜色，不得把多个 PC 规格合并到一张图。
- 北美生活方式场景应真实、易理解，并与产品用途匹配。
- 每个图号的 `direct01`、`direct02`、`direct03` 分别由三个全新单版生成 Subagent 串行生成；不同图号独立推进，但同时调用生图工具的单版生成 Subagent 最多三个，三张不同图片不得合并为一次调用；三版提示词必须有明确调整，不能完全相同。
- 每个单版生成 Subagent 只执行一次生图调用；不得把其他 direct 作为输入、参考图或上下文。调用失败或结果作废时，由新的替补 Subagent 补生成同一 direct 编号，其他图号任务链不受阻塞。
- 三版均为 1:1 正方形直接生成结果。来源不明、内容不符、非正方形、其他产品、其他品牌、其他语言或跨 Session 内容均作废，不计入三版。
- 禁止把上一张图的版式、文案或场景自动带入当前图；出现跨图污染时，该版本作废。
- 生成中断、超时或未稳定进入下一次调用时，不得标记完成。核对当前工具直接生成目录中的文件数量、大小和时间戳，从缺失图型与序号继续补齐。
- 英文出现明显错误时直接重新生成；多次生成后仍错误则跳过该图。最终交付不得用本地文字覆盖补救，并须保留已有直接生成版本。

## Direct 门禁

- 每张 direct 都必须由一个全新独立验收 Subagent 输出 `PASS` 或 `FAIL`、具体违规项和处理动作；主 Agent、单版生成 Subagent 自检或来源清单记录不能替代验收。
- 验收 Subagent 必须重新执行 `view_image` 打开当前 direct 及其实际使用的全部产品、面料和结构参考，不得依赖主 Agent、生成 Subagent或上一版的图片上下文。
- 验收范围包括来源与比例、英文、当前产品身份、面料映射、颜色、结构、系带/滚边、售卖数量、真实尺寸和载体适配。
- `FAIL` 版本按当前工具规则记录或隔离，不计入三版；只针对验收指出的违规项调整提示词，重复全部产品不可变项，并由新的替补生成 Subagent 补生成当前任务链的同一缺失序号，其他图号按各自验收结果继续推进。
- 同一图号取得 `direct01`、`direct02`、`direct03` 三张 `PASS` 版本后，才可进入选片。

### 每张 direct 检查清单

- [ ] 当前 direct 已保存到当前工具规定的直接生成路径
- [ ] 当前工具要求的源文件路径、源/目标哈希、尺寸、提示词编号和来源清单均完整，结果可唯一定位
- [ ] 当前 direct 为当前 TEMU 产品、英文画面和正方形构图；无其他 Session、品牌、语言、产品或上一图内容混入
- [ ] 主产品身份、几何轮廓、长宽厚比例、结构、针位/绗缝、缝线、边缘、系带/滚边、面料、颜色和售卖数量与主产品身份参考一致，其他参考未覆盖产品身份；定制选项对比图展示的每个结构状态分别符合对应素材。
- [ ] 定制产品的形状能力与需求表或用户确认一致：未明确支持异型时只按主产品身份参考的矩形轮廓定制长宽，未新增梯形、三角形、圆角裁切或其他异型选项；明确支持时输出轮廓及边长、角度、圆角半径等几何信息与已锁定依据一致。
- [ ] 主图有文字时，文字直接叠加在背景或场景上，文字与背景之间没有卡片、底板、胶囊、色块或半透明遮罩。
- [ ] 面料仅保留参考图中的颜色、印花和微观织纹，未把折叠、旋拧、褶皱、阴影或高光形状生成成连续浮雕、波浪纹或重复条纹。
- [ ] 定制产品的堆叠主图的层数符合需求表或参考图；未指定时不少于 3 层，且各层结构、尺寸一致、叠放真实；任意两层至少在颜色或面料之一不同，各层差异均有已查看且可追溯的素材，否则当前版本为 `FAIL`
- [ ] 面料细节图按需求表中的面料类别使用对应实拍，同倍率、同光线、同白平衡展示；未用 `Solid`、`Print` 代替面料类别，缺少实拍或映射不明时已阻塞该图
- [ ] 场景中产品大小符合真实尺寸；固定尺寸选择匹配载体，连续定制尺寸按载体完整可用区域生成匹配成品，且未留空或溢出；如果是坐垫产品，沙发场景中产品是唯一可见的座垫，产品下方无原座垫第二层座垫；验收结果必须单独记录本项，任一条件不满足或未记录均为 `FAIL`
- [ ] `N PC` 商品在同一使用场景中准确展示 `N` 件；数量未知时未推断多件装；同时存在多颜色与多个 PC SKU 时，当前图只对应一个 PC 规格、使用统一选定颜色且未合并其他 PC 规格，任一条件不满足均为 `FAIL`
- [ ] 颜色展示副图按“实拍图颜色 > 面料颜色图/色卡图 > 颜色文字 > 留白”处理
- [ ] 除需求表或用户明确标注的“定制模板”与“色号图”外，所有色块均无颜色编号；主图色块直接叠加在背景或场景上，无底板、底色、颜色编号或颜色名字
- [ ] 如使用关键 JPG 参考图，只参考材质、场景、版式或信息层级，没有照搬他人内容
- [ ] 图片内无中文、乱码、机器直译腔、错拼、遮挡或溢出
- [ ] 所有输入参考图均已执行 `view_image` 并记录角色
- [ ] 当前验收 Subagent 已重新查看当前 direct 及其实际使用的全部产品、面料和结构参考。

### 进入选片前检查

- [ ] 每个未跳过的图型均有 `direct01`、`direct02`、`direct03` 三张经独立验收为 `PASS` 的版本
- [ ] `FAIL`、作废或污染图片未计入三版，并已按当前工具规则记录或隔离、补生成缺失序号
