# 设计、文案与提示词

## 设计原则

- 突出卖点，符合 TEMU 美国站购物场景：清楚、直接、真实、产品识别强。
- 文案严格使用需求表中的英文。发现拼写、单复数、明显语法或单位格式错误时，只做保持原意的最小修正；不得改变卖点角度、补充未提供信息或夸大性能。
- 需求表没有文案且没有说明无文字、参考图中有文字时，可把参考图文字作为文案参考。
- 图片内不得出现中文。
- 整套图片的风格、配色、元素和字体保持一致。参考图只用于版式、氛围和视觉语言，不得照搬人物容貌、完整文案、图标或品牌元素。
- 人物年龄、体型、家庭环境、家具尺度、使用方式和审美应符合美国目标市场预期。抱枕、坐垫、床品、家居用品、宠物用品、婴童用品等必须按真实尺寸和使用对象校验比例。
- 座垫等需要载体的产品：可定制尺寸必须与载体一致；固定尺寸必须选择匹配载体；载体上不得留空。提示词必须写明这一比例要求。

## 资料与优先级

- 同目录有 VI 手册 / brand guide / logo 规范时，严格遵守其配色、字体、logo 和版式。
- 需求表是需求、参考、文案、尺寸、输出类型、颜色/SKU 和禁用信息的最高内容依据；TEMU 平台规范具有更高合规优先级。
- 平台规范、需求表或用户口头要求发生冲突时，先暂停并说明冲突点，不要硬做。
- 必须理解产品尺寸的含义，并用人物、家具、手持、宠物、儿童或实际使用环境校验画面比例。
- 必须识别 WPS `DISPIMG` 单元格中的嵌入图片。

## 颜色规则

**产品颜色展示**

1. 优先使用产品实拍图中的颜色。
2. 制作颜色展示副图且有对应面料颜色图或色卡图时，按该依据为产品改色。
3. 没有面料图但需求表或文件名有颜色文字时，按颜色文字改色。
4. 颜色编号、颜色文字和面料图都没有时，颜色展示区域留白，只生成版式和已有文案，不得编造颜色。

**色块素材缺失**

需求表要求放置色块，但没有找到全部颜色编号对应的实际图片时，使用已有颜色图占位，缺失部分由用户后续手动补充。

## 提示词产出格式

每张图使用以下八个字段；可按图片需求略微调整，但不要保留方括号及其说明文字。参考图不得提供产品，只能参考版式、场景、人物氛围和构图，也不得照搬人物。

```text
【图片比例】
1:1正方形构图

【画面目标】
这张图要解决的销售任务：吸引点击、解释功能、展示材质、证明尺寸、突出定制、表现舒适感等。

【画面构成】
主体产品位置、人物(默认欧洲年轻女性,如有具体需求则按照需求表来)/场景、背景、道具、文字区域、版式层级。

【产品输入】
写明使用哪些产品实拍图作为图生图垫图，是否加入本文件夹或需求表中的参考图。必须写明“保留产品结构、面料、颜色和比例，不重设计产品”。不要在提示词中描述产品细节，产品细节以垫图为准。

【颜色/面料】
是否为颜色展示副图；是否找到面料颜色图、色卡图、颜色代号或颜色文字；只描述改色依据和展示版式，依据不足时颜色展示区域留白，不描述或重构产品细节。

【view_image 输入记录】
列出当前 Session 中已执行 view_image 的图片及角色：
- Image 1: edit target
- Image 2: product identity reference
- Image 3: detail reference
- Image 4: layout reference
根据实际情况增减。

【文案】
必须包含需求表中出现的文案，不要夸大卖点。不得出现中文、乱码或新增卖点。

【风格】
TEMU 美国站电商图风格，清楚、真实、产品优先，符合美国消费者购物场景。
版式/配色/字体风格要使用本系列图的统一风格，此风格在第一次生成时根据产品与需求来确定。
```

图中有产品出现在场景里时，加入以下固定提示词：

```text
场景充满生活感，专业电商摄影风格，专业打光，保持产品的透视角度正确，产品的光影自然的融入场景中，looks like a premium furniture brand catalog photo
```

## TEMU 平台规范

**主图**

- 产品不得被裁切，不得用夸张透视或错误参照物误导尺寸。

**副图**

- 可做场景图、卖点文案、结构说明、尺寸说明、材质细节、定制选项、使用前后对比、颜色选择、SKU 展示或规格展示，信息可以比主图更完整。
- 颜色、图案、尺寸、数量或定制选项必须准确，避免误解实际可选范围和售卖内容。
- 尺寸图必须结合真实产品尺寸和常见参照物，避免把产品做得过大或过小。

**合规限制**

- 禁止无依据的绝对化或误导词，例如 `best`、`#1`、`perfect`、`100% safe`、`guaranteed`、`forever`，除非需求表提供可核验依据且平台允许。
- 禁止医疗、治疗、矫正、疾病改善或功效暗示，除非有明确资质和需求表依据。
- 没有授权或需求表依据时，不得添加 `certified`、`approved`、`official`、`patented` 等认证表达。
- 禁止未经授权使用他店图片、商标、logo 或角色。
