# 设计、文案与提示词

## 设计原则

- 突出卖点，符合北美市场应用场景。
- 图片文案优先使用需求表中的英文或用户确认的内容；没有现成文案时，可依据当前图号的销售任务和已核实的产品事实拟写简短英文文案。需求表与反推专用参考图均未提供所需正文或副标题时，补写宽泛、简短的介绍性说明，不写具体数值、规格、认证等可追责信息。不得新增未经确认的规格、认证或绝对化表述。发现拼写、单复数、明显语法或单位格式错误时，只做保持原意的最小修正。
- 图片内不得出现中文。
- 当前图片同时为非 SKU、非白底且非纯场景图，分配给当前 direct 的反推专用参考图采用标题式信息层级，并且需求表未明确本图无文案时，加入标题和副标题。反推专用参考图只决定是否采用标题式信息层级，不得作为未经核实的产品事实来源。
- 只要图片中出现主标题，就必须同时加入简短副标题；需求表或反推专用参考图只提供主标题时，按本节文案来源规则补写副标题。
- 整套图片统一字体家族、色彩关系和图形语言，不统一背景、场景或版式结构。反推专用参考图只供主 Agent 反推允许的版式、文案、Icon、场景和卖点视觉叙事信息，不得进入生图输入；产品外观只以 manifest 实拍为准。
- 人物年龄、体型、家庭环境、家具尺度、使用方式和审美应符合美国目标市场预期。抱枕、坐垫、床品、家居用品、宠物用品、婴童用品等必须按真实尺寸和使用对象校验比例。
- 需求表或用户明确商品为 `N PC`(例如2PC/4PC等) 时，同一使用场景必须准确展示 `N` 件产品(海绵除外,根据需求进行展示或者用填充好的坐垫进行展示)；数量未知时不得推断多件装。
- 主图突出完整产品；副图根据卖点与素材关系选择视觉叙事、构图重心和信息层级。
- 三版必须使用不同的视觉叙事和版式结构；仅移动产品、人物或文字，或者只改变拍摄角度，不算不同版式。
- 主图有文案时，标题必须成为仅次于产品的第二视觉焦点(文案字号足够大)：使用粗体或特粗体展示字体，字号明显大于副标题，且不允许使用纯黑/灰等无颜色倾向的字体颜色；标题色优先使用 VI 或明亮暖色，主图的文案添加白色描边。所有图片的标题字号都应该足够大。
- 仅限主图：主图文字必须直接叠加在背景图或场景图上，文字与背景之间不得增加卡片、底板、胶囊、色块或半透明遮罩；允许文字自身使用描边和轻微投影。
- 全套统一字体家族与色彩关系。
- 非纯场景副图必须明确布局结构、产品区域、文字区域和辅助模块，产品、文案与辅助模块形成完整视觉路径，不得出现无用途的大面积留白；不得为了填充画面新增无依据文案。文案须遵守本节的来源规则，其余空间只能使用真实细节特写、尺寸线、色块或场景切片等有依据的内容。
- 图中每个卖点小标题都必须搭配简短正文；细节/卖点/放大特写的卡片、气泡以及 Icon 下方的卖点均适用，正文不要过长。
- 需求表中要求每个颜色各生成一张场景图或 SKU 图时，本流程每种面料仅生成一个颜色的SKU：优先使用用户指定颜色，其次使用需求表指定颜色，否则使用已锁定的产品实拍基准色；多个实拍颜色无法确定唯一基准时阻塞。
- 同时存在多颜色与多个 PC SKU 时，每个 PC 规格单独规划一个 SKU 图号并准确展示对应件数，所有图号使用上述统一颜色；每个图号仍分别生成 `direct01`、`direct02`、`direct03`。
- 当商品为海绵、当前图号为纯场景图/多场景图、用户和需求表均未明确要求露出海绵，且分配给当前 direct 的反推专用参考图不存在或未露出海绵时，只将是否露出海绵作为场景展示方式，不提取参考图中的产品外观；在提示词中按已确认的真实尺寸和用途展示海绵填充后的坐垫使用效果，不直接露出海绵商品，也不暗示坐垫套或成品坐垫属于售卖内容。将该 direct 按“目标画面不出现产品”处理，不设置 `edit target`，也不将海绵实拍作为实际生成输入。

## 资料与优先级

- 同目录有 VI 手册 / brand guide / logo 规范时，严格遵守其配色、字体、logo 和版式。
- 需求表是需求、参考、文案、尺寸、交付类型、内容图型和禁用信息的最高内容依据。
- 需求表与用户口头要求发生冲突时，且处于Plan mode，请向用户提问。
- 必须理解产品尺寸的含义，并用人物、家具、手持、宠物、儿童或实际使用环境校验画面比例。
- 必须识别 WPS `DISPIMG` 单元格中的嵌入图片。

## 颜色规则

**产品颜色展示**

1. 先按当前 direct 的场景、构图和版式选择 `edit target` 与确实需要的其他实拍，再只为这些已选实拍匹配准确色块；不得提前要求 manifest 全部实拍完成配对。
2. 未要求改色时，输出颜色以已选实拍的对应色块为准，用它作为实拍图的真实颜色。产品纹理、光泽以色块为准。
3. 要求改色时，输出颜色以目标色块为准；仍传入已选实拍各自的对应色块用于来源登记，但不得让原配色块覆盖目标色块。
4. 已选实拍缺少明确对应色块时阻塞当前 direct；要求改色但缺少目标色块时阻塞当前图号。不得根据实拍观感、近似色或颜色文字猜色。
5. 同色的多张已选实拍可以共用一张对应色块；实际生成输入只传一次，并明确记录该色块对应的全部实拍。
6. 对应色块和目标色块默认只作为颜色依据，不得作为可见元素生成；只有需求明确要求展示色块时才在画面中呈现。

**色块展示**
> 此规则在生成符合条件图片的提示词中体现。

- 其他图片的色块不得显示颜色编号，包括颜色代号、Color ID 和 SKU 色号；普通副图可以保留需求表提供的颜色名字。
- 主图要求添加色块时，色块必须直接叠加在背景图或场景图上，色块组与背景之间不得增加承载卡片、底板或底色；主图与非色号图/定制模板的图中色块上不得显示颜色编号或颜色名字。

**色块素材缺失**

需求表要求放置色块，但没有找到全部颜色编号对应的实际图片时，仅使用已有颜色图占位。

## 提示词编写步骤

首次生图前，按以下顺序完成当前图号的 `direct01`、`direct02`、`direct03` 三版提示词。

1. 显式调用一个全新的 `temu_image_inspector`，只查看映射中的全部产品实拍并逐张返回产品可见事实、完整度、视角、主体裁切/遮挡情况和整体三维结构清晰度；反推专用参考图缺失不阻塞，其他依据冲突时先阻塞。
2. 主 Agent 根据全部产品实拍的查看结果锁定产品真实性底线：产品身份、轮廓、结构、纹理、比例、实拍基准色和禁止偏离项。除非用户、需求表文字或已声明的结构标注素材明确给出，产品形状、轮廓、截面和厚薄关系不得在产品真实性底线或生成提示词中被命名、推断或重述；只用实际输入的 `Image N` 指代并要求保持实拍。手持、按压、弯折、斜放和透视只表示姿态，不得据此定义固定几何结构。
3. 主 Agent 读取需求表中的文字、尺寸、售卖数量、交付类型、内容图型、颜色/面料要求和现成英文，查看需求表中的全部图片；同时查看需求表以外的颜色/面料、结构细节、插入或辅助图片。将全部图片分类为反推专用参考图、颜色/面料依据、结构细节、插入或辅助素材，或者不使用。
4. 根据需求表和已核实素材确定当前图号的交付类型、内容图型、目标构图比例、单一销售任务、真实尺寸、售卖数量、定制能力和颜色/面料要求。定制产品须确认形状能力：未明确支持异型时只允许依据产品尺寸的定制范围定制长、宽、厚，不新增其他异型选项。
5. 逐张分析已确定的反推专用参考图，只提取允许的版式结构、区域比例、场景、背景、道具、光线、视觉层级、展示数量、图片表达的卖点意图、体现卖点的场景/动作/产品状态/道具关系/对比/真实细节特写等视觉元素(如果没有则不提取，不要写“无xx”)，以及现成英文和标题/副标题信息层级。反推的卖点作为视觉叙事候选；不符合当前产品的功能、结构、功效及其视觉元素不得保留。根据当前图号的销售任务将反推结果分配给各 direct；没有反推专用参考图时，依据销售任务自行规划三版。将分配、自行规划、卖点取舍写入 `【内部参考反推记录】`。
6. 基于销售任务和各 direct 的反推结果或自行规划，确定三版各自的场景、视觉叙事、构图和版式；每个 direct 都必须通过符合当前产品的场景、使用动作、产品状态、道具关系、对比或真实细节等视觉元素表达销售任务，即使去掉全部文案仍能理解核心卖点。文案、Icon 和文字标签只用于强化，不得成为卖点的唯一表达载体。人物只在需求表、图片用途、真实比例校验、经确认的卖点视觉表达需要或反推结果要求时加入，无依据时不加入人物。
7. 按设计原则的文案来源规则确定当前图号的完整英文文案。先使用需求表或用户确认的英文；缺失时由主 Agent 根据销售任务和已核实产品事实拟写。反推专用参考图采用标题式信息层级时按设计原则决定标题和副标题，不得让生图工具自行拟写或补全。
8. 根据当前图号的颜色/面料要求和三版规划，分别为每个 direct 选择实际生成输入。只要当前 direct 的目标画面出现产品，就必须先从 manifest 产品实拍中唯一指定一张最符合该版产品姿态、视角、完整度和构图需求的图片作为该 direct 的 `edit target`，再确定确实需要的其他实拍；三个 direct 可以选择同一路径，也可以分别选择不同路径，不得为了统一而强制复用。其他产品实拍只能承担 `primary product identity`、侧面、厚度、底面或局部结构补充角色，不得再标记为 `edit target`。实拍全部选定后，才为该 direct 的每张已选实拍匹配准确色块；同色色块去重后，与实拍、目标色块及其他必需素材一起编排为该 direct 独立、连续的 `Image N`。逐张记录实拍与色块的对应关系，以及结构细节、插入或辅助素材角色；实际生成输入记录与内部反推记录不得混排。
    - 当前 direct 的目标画面不出现产品时，不设置 `edit target`，也不传入无用途的产品实拍。
    - 当前 direct 选择展示完整产品的实拍作为 `edit target` 时，先排除主体被裁切、关键结构被遮挡或因视角过平导致整体结构难以判断的图片；优先选择能清晰呈现产品整体轮廓、顶面、侧面、厚度及前后纵深关系的斜俯视三分之四视角（约 30°–45°）。没有该视角时，选择能最清晰、完整呈现产品三维结构的其他合格视角；当前 direct 需要完整产品底图但没有任何合格实拍时阻塞。
    - 实拍姿态与目标姿态不同时，在符合上一条完整度和三维结构清晰度要求的候选中，优先选择最接近目标姿态的完整产品实拍作为该 direct 的 `edit target`，并按需加入侧面或厚度实拍；明确旋转后只改变姿态，不重新设计产品。
    - 已选实拍找不到明确对应色块时阻塞当前 direct；不得因此改选不适合构图的实拍，也不得根据照片观感或颜色文字猜测。未被当前 direct 选中的实拍无需匹配或验证色块。
    - 同色的多张已选实拍可以共用同一张对应色块，实际输入只传一次，并在记录中列明它对应的全部实拍。
    - 实拍图只有一种颜色/面料，但需求要求生成其他颜色/面料时，除每张已选实拍的对应色块外，再将目标色块作为实际生成输入；没有目标色块时阻塞当前图号。
    - 同一图号的 `direct01`、`direct02`、`direct03` 必须使用相同的目标颜色/面料和英文文案。多个独立场景图号有多种颜色/面料可用时，优先在不同图号间分配不同颜色/面料；数量不足时允许复用。
    - 同一张多场景图要出现多个产品，且产品有不同的面料/颜色/印花时，每个场景优先使用不同的颜色/面料/印花；数量不足时允许复用。
9. 冻结三版共同基准：产品真实性底线、当前图号的销售任务与核心卖点、目标构图比例、尺寸、售卖数量、定制能力、目标颜色/面料、目标色块和完整英文文案；另行冻结每个 direct 自己的 `edit target`、其他已选实拍、实拍与对应色块的映射、其他实际生成输入及角色。`edit target` 路径不属于三版共同基准，不要求三版相同；不同底图视角不得导致产品身份或共同事实改变。三版只允许改变各自已规划的场景、视觉叙事、构图和版式，不得改变销售任务、核心卖点或目标构图比例。
10. 按下方字段格式写出三版提示词；每版都明确说明该 direct 自己的 `edit target`、共同基准、其他实际输入角色、版式结构、产品区域、文字区域和辅助模块。不适用字段删除，不得保留说明性占位符。
11. 将 `额外添加的提示词` 中符合条件的内容加入提示词；符合多条时把符合的全部加入。
12. 生图前检查三版均已明确并使用当前图号冻结的同一目标构图比例，英文文案、实际输入角色、真实比例和版式结构完整，并分别写明能够表达核心卖点的视觉元素；无文案时删除文案字段并且不规定字体。提示词不得包含未传入图片的路径、名称、图片编号或引用，不得包含中文、无依据的产品、颜色、人物、文案或功效信息，不得出现冗长的负面提示词，也不得使用 `generous breathing room`、`generous spacing`、`clean empty background` 等主动制造空白的泛化表述。

## 提示词产出格式

提示词描述统一使用中文，图片内文案仍使用英文(如果有的话)。
每张图的三版提示词均按以下九个字段顺序编写；不适用字段删除，不得保留说明性占位符。
无文案时删除文案字段，并且提示词中不允许规定字体。
`【图片比例】`只控制画面构图，不要求生成文件的像素宽高严格匹配；同一图号的三个 direct 必须使用相同的目标构图比例。

```text
prompt开始固定提示词: `Amazon US E-commerce Product Imagery`

【图片比例】
按当前图号的交付类型选择；只保留最终选定的构图比例，不保留选择说明或其他候选比例。
主图/副图：1:1 正方形构图
详情页：从 1:1 正方形构图、4:3 横构图、16:9 横构图、3:4 竖构图、9:16 竖构图中按本图实际情况选择一种
高级 A+：21:9 横构图
普通 A+：8:5 横构图

【画面目标】
写明这张图要解决的销售任务和核心卖点：解释功能、展示材质、证明尺寸、突出定制、表现舒适感等。

【产品输入】
只写明当前 direct 的实际生成输入：`2560px拍摄图/_manifest.json` 中已选的产品实拍、每张已选实拍的对应色块，以及按需加入的目标色块、结构细节、插入或辅助素材。不得填写或上传原始拍摄图路径。当前 direct 的目标画面出现产品时，将为该版单独选定的唯一底图写为 `Image 1: edit target and sole editable product base for this direct`；不同 direct 的 `Image 1` 可以对应不同的 manifest 产品实拍。其他实拍只补充厚度、底面或局部结构，其他实际输入只承担已声明的角色，不得再标记为 `edit target` 或作为第二张可编辑产品底图。逐项写明对应色块服务于哪一张或哪几张实拍。必须写明“产品结构、纹理、光泽、比例和细节以实拍为准，产品颜色以对应色块为准并修正实拍拍摄色差；色块不得改变其他产品属性，也不得出现在成图中，除非需求明确要求展示”。不得用类别常识或主观视觉判断重述产品细节，使用当前 direct 的实际输入序号代指产品，例如："Image 1 中的产品"。除非用户、需求表文字或已声明的结构标注素材明确给出，产品形状和轮廓不得在产品真实性底线或生成提示词中被命名、推断或重述；手持、按压、弯折、斜放和透视只表示姿态，不得据此定义固定几何结构。
定制产品还须指明承载已锁定系带数量与位置、滚边数量等结构基准的实拍图编号，并将基准作为生成约束；这些文字不得替代垫图或重新定义产品结构。并且必须将素材中的结构图作为实际生成输入。

【画面构成】
写明版式结构、主体产品位置与占比、场景、背景、道具、文字区域、辅助模块和信息层级；明确承载核心卖点的场景、使用动作、产品状态、道具关系、对比或真实细节等非文字视觉元素，使画面能表达销售任务。文案、Icon 和文字标签不得作为卖点的唯一表达载体，必须配合视觉元素。不得保留未分配用途的大面积空区。
除了SKU、明确要求或内部反推确定为白底构图的情况，不要直接在版式/白底上放产品图，产品要与场景结合。`N PC` 商品写明同一场景中的准确产品数量。

【颜色/面料】
未改色时，逐项指定对应色块的 `Image N` 及它校正的实拍 `Image N`；要求改色时，另行指定目标色块的 `Image N`，明确最终产品颜色只以目标色块为准。色块只控制颜色，不描述或重构产品的面料、纹理、光泽、结构、比例或细节；除非需求明确要求展示，否则色块不得成为画面元素。

【view_image 实际输入记录】
只列出当前 direct 中已执行 `view_image` 且将实际传给生图工具的图片及角色；编号和角色不得沿用其他 direct：
- Image 1: edit target
- Image 2: primary product identity
- Image 3: target color authority
- Image 4: detail/structure
- Image 5: insert/supporting asset
根据实际情况增减。

【文案】
逐字写入主 Agent 已确定的英文标题、副标题、卖点小标题及其对应正文，包括 Icon 下方卖点的简短正文；不得写入决策说明，不得要求生图工具自行拟写或补全，不得出现中文。

【风格】
整套图统一品牌气质、字体家族、色彩关系和图形语言，不统一背景、场景或版式结构。

【版式/字体与配色】
按需直接写明版式结构、产品区域、文字区域、辅助模块、字体大小与配色(字体与配色的提示词必须整套统一[无衬线体/圆体/衬线体等])。不得使用主动制造空白的泛化表述。
```

`【内部参考反推记录】` 由主 Agent 独立保留，不属于上述提示词。每张反推专用参考图记录绝对路径、分析角色、提取的版式/场景/展示数量、卖点意图及其视觉元素、现成英文和标题/副标题信息层级，并记录支持该卖点的需求表、用户确认或已核实产品事实来源，以及商品规格的真实来源；不得写入提示词文件或传给生成 Subagent 和生图工具。

## 额外添加的提示词

> 提示词里的`[]`和其中的内容为变量，根据规定或实际情况来改动

- 当前 direct 的目标画面出现非定制产品时，将 `[产品尺寸]` 替换为需求表或用户确认的真实产品尺寸并加入提示词；尺寸来源缺失时阻塞，不得猜测：

    ``` prompt
    产品真实尺寸为[产品尺寸]，仅用于理解产品在现实中的大小，并校验产品与人物、载体和场景的比例。除尺寸图外，不得在成图中以文字、数字、尺寸线或尺寸标注显式展示产品尺寸；尺寸图按已确认的真实尺寸正常标注。
    ```

- 当图中有产品出现在场景里时，加入以下固定提示词：

``` prompt
场景充满生活感，布景合适，专业电商摄影风格，专业打光，保持产品的透视角度正确，产品的光影自然的融入场景中
```

- 当图中有坐垫之类的产品出现在应该符合尺寸载体上时，加入以下提示词，将 `[载体]` 替换为实际的载体名字：

    ``` prompt
    产品尺寸与[载体]完美匹配， [载体]上不允许出现空隙
    ```

    - 包括但不限于的情况：
    - 应用情况：长凳垫/九针垫 放在 沙发/飘窗/长凳/长椅 上时

    ``` prompt
    产品(产品的名字)替代[载体]原有的坐垫，在产品下方不允许出现[载体]自带的坐垫，产品下方不允许出现[载体]自带的坐垫。
    ```

    - 包括但不限于的情况：
    - 应用情况：长凳垫/九针垫 放在 沙发 上时

    ``` prompt
    坐垫的厚度必须与原图一致。
    ```


## 平台规范

**主图**

- 产品不得被裁切，不得用夸张透视或错误参照物误导尺寸。
- 主图中的产品必须占据足够大的视觉空间。
- 如果内部反推确定为白底构图，且需求中没明确要求带场景或载体，则生成白底图(文案按需加入)。

**内容图型**

- 如果场景图展示多个场景，并且产品有多种颜色的情况下，场景图中应展示不同颜色的产品。
- 主图、副图、详情页、高级 A+ 和普通 A+ 均可按需求包含场景图、卖点文案、结构说明、尺寸说明、材质细节、定制选项、使用前后对比、颜色选择、SKU 展示或规格展示；副图的信息可以比主图更完整。
- 颜色、图案、尺寸、数量或定制选项必须准确，避免误解实际可选范围和售卖内容。
- 尺寸图必须结合真实产品尺寸和常见参照物，避免把产品做得过大或过小。

**合规限制**

- 禁止无依据的绝对化或误导词，例如 `best`、`#1`、`perfect`、`100% safe`、`guaranteed`、`forever`，除非需求表提供可核验依据且平台允许。
- 禁止医疗、治疗、矫正、疾病改善或功效暗示，除非有明确资质和需求表依据。
- 没有授权或需求表依据时，不得添加 `certified`、`approved`、`official`、`patented` 等认证表达。
- 禁止未经授权使用他店图片、商标、logo 或角色。
