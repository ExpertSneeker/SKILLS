# 设计、文案与提示词

## 设计原则

- 突出卖点，符合北美市场应用场景。
- 文案优先使用需求表中的英文。发现拼写、单复数、明显语法或单位格式错误时，只做保持原意的最小修正。
- 单张图片如果没有文案且没有明确说明无文案、但参考图中有文字时，把参考图文字作为文案参考。
- 图片内不得出现中文。
- 整套图片的风格、配色、元素和字体保持一致。参考图只用于版式、氛围和视觉语言的参考，不得照搬人物容貌或品牌元素。
- 人物年龄、体型、家庭环境、家具尺度、使用方式和审美应符合美国目标市场预期。抱枕、坐垫、床品、家居用品、宠物用品、婴童用品等必须按真实尺寸和使用对象校验比例。
- 坐垫等需要载体的产品：可定制尺寸产品按载体完整可用区域生成匹配成品；固定尺寸必须选择匹配载体；产品不得溢出，侧边、前后和产品之间不得留空。坐垫用于沙发时必须替换原有座垫，不得叠放在原座垫上。提示词必须写明这些要求。
- 需求表或用户明确商品为 `N PC`(例如2PC/4PC等) 时，同一使用场景必须准确展示 `N` 件产品；数量未知时不得推断多件装。
- 主图突出完整产品；副图根据卖点与素材关系选择视觉叙事、构图重心和信息层级。
- 三版必须使用不同的视觉叙事。
- 主图有文案时，标题必须成为仅次于产品的第二视觉焦点(文案字号足够大)：使用粗体或特粗体展示字体，字号明显大于副标题，且不允许使用纯黑/灰等无颜色倾向的字体颜色；标题色优先使用 VI 或明亮暖色，主图的文案添加白色描边。所有图片的标题字号都应该足够大。
- 全套统一字体家族与色彩关系。
- 副图的版式应该丰富协调无留白，可适应版式适当添加文案。
- 需求表中要求每个颜色各生成一张场景图或 SKU 图时，本流程只生成一个统一颜色：优先使用用户指定颜色，其次使用需求表指定颜色，否则使用已锁定的产品实拍基准色；多个实拍颜色无法确定唯一基准时阻塞。
- 同时存在多颜色与多个 PC SKU 时，每个 PC 规格单独规划一个 SKU 图号并准确展示对应件数，所有图号使用上述统一颜色；每个图号仍分别生成 `direct01`、`direct02`、`direct03`。

## 资料与优先级

- 同目录有 VI 手册 / brand guide / logo 规范时，严格遵守其配色、字体、logo 和版式。
- 需求表是需求、参考、文案、尺寸、输出类型 和禁用信息的最高内容依据。
- 需求表与用户口头要求发生冲突时，且处于Plan mode，请向用户提问。
- 必须理解产品尺寸的含义，并用人物、家具、手持、宠物、儿童或实际使用环境校验画面比例。
- 必须识别 WPS `DISPIMG` 单元格中的嵌入图片。

## 颜色规则

**产品颜色展示**

1. 优先使用映射中的产品实拍图颜色。
2. 制作颜色展示副图且有对应面料颜色图或色卡图时，按该依据为产品改色。
3. 没有面料图但需求表或文件名有颜色文字时，按颜色文字改色。

**色块展示**
> 此规则在生成符合条件图片的提示词中体现。

- 其他图片的色块不得显示颜色编号，包括颜色代号、Color ID 和 SKU 色号；普通副图可以保留需求表提供的颜色名字。
- 主图要求添加色块时，色块必须直接叠加在背景图或场景图上，色块组与背景之间不得增加承载卡片、底板或底色；主图与非色号图/定制模板的图中色块上不得显示颜色编号或颜色名字。

**色块素材缺失**

需求表要求放置色块，但没有找到全部颜色编号对应的实际图片时，仅使用已有颜色图占位。

## 提示词编写步骤

首次生图前，按以下顺序完成当前图号的 `direct01`、`direct02`、`direct03` 三版提示词。

1. 整理需求表、真实尺寸、映射中的产品实拍、VI、颜色或面料依据、参考图和 `view_image` 记录；依据冲突时先阻塞。
2. 锁定三版共有的产品结构、面料、颜色、比例、英文文案、颜色依据和禁止项，不得在版本间改变。
3. 确定本图的输出类型、单一销售任务、场景和构图；人物只在需求表、图片用途或真实比例校验需要时加入，无依据或无必要时不加入人物。
4. 列出当前 Session 已查看的输入图片及角色，区分产品输入与版式、风格或场景参考。
5. 按下方九字段格式完整写出三版提示词；不适用字段删除，不得保留说明性占位符。
6. 生图前检查三版的不可变项一致，均为 1:1，英文文案、输入角色和真实比例完整，且没有中文或无依据的产品、颜色、人物、文案和功效信息。

## 提示词产出格式

提示词描述统一使用中文，图片内文案仍使用需求表英文。
每张图的三版提示词均按以下九个字段顺序编写；不适用字段删除，不得保留说明性占位符。
不允许出现冗长的负面提示词。

```text
【图片比例】
1:1正方形构图

【画面目标】
这张图要解决的销售任务：吸引点击、解释功能、展示材质、证明尺寸、突出定制、表现舒适感等。

【画面构成】
主体产品位置、场景、背景、道具、文字区域和版式层级；人物只在需求表、图片用途或参考图中出现时加入。
除了SKU或明确要求的情况，不要直接在版式/白底上放产品图，产品要与场景结合。
有载体时写明固定尺寸选择匹配载体，或可定制尺寸产品按完整可用区域生成匹配成品，且不得留空或溢出；用于沙发时必须写明：先移除原有座垫；产品是唯一可见的座垫；产品下方不得出现原座垫或第二层座垫。`N PC` 商品写明同一场景中的准确产品数量。

【产品输入】
写明使用 `2560px拍摄图/_manifest.json` 中哪些目标文件作为图生图垫图，是否加入本文件夹或需求表中的参考图。不得填写或上传原始拍摄图路径。必须写明“保留产品结构、面料、颜色和比例，不重设计产品”。不要在提示词中描述产品细节，产品细节以垫图为准。
定制产品还须指明承载已锁定系带数量与位置、滚边数量等结构基准的实拍图编号，并将基准作为验收约束；这些文字不得替代垫图或重新定义产品结构。并且必须提供素材中的结构图作为参考输入。

【颜色/面料】
不描述或重构产品细节。

【view_image 输入记录】
列出当前 Session 中已执行 view_image 的图片及角色：
- Image 1: edit target
- Image 2: product identity reference
- Image 3: detail reference
- Image 4: layout reference
根据实际情况增减。

【文案】
不得出现中文。

【风格】
TEMU 美国站电商图风格，清楚、真实、产品优先，符合美国消费者购物场景。
整套图统一品牌气质、字体家族和色彩关系，不统一固定版式。

【版式/字体与配色】
版式风格，字体大小与配色(字体与配色的提示词必须整套统一[无衬线体/圆体/衬线体等])，版式参考哪个参考图(如果有参考图)。
```

图中有产品出现在场景里时，加入以下固定提示词：

```text
场景充满生活感，专业电商摄影风格，专业打光，保持产品的透视角度正确，产品的光影自然的融入场景中，looks like a premium furniture brand catalog photo
```

## TEMU 平台规范

**主图**

- 产品不得被裁切，不得用夸张透视或错误参照物误导尺寸。

**副图**

- 如果场景图展示多个场景，并且产品有多种颜色的情况下，场景图中应展示不同颜色的产品。
- 可做场景图、卖点文案、结构说明、尺寸说明、材质细节、定制选项、使用前后对比、颜色选择、SKU 展示或规格展示，信息可以比主图更完整。
- 颜色、图案、尺寸、数量或定制选项必须准确，避免误解实际可选范围和售卖内容。
- 尺寸图必须结合真实产品尺寸和常见参照物，避免把产品做得过大或过小。

**合规限制**

- 禁止无依据的绝对化或误导词，例如 `best`、`#1`、`perfect`、`100% safe`、`guaranteed`、`forever`，除非需求表提供可核验依据且平台允许。
- 禁止医疗、治疗、矫正、疾病改善或功效暗示，除非有明确资质和需求表依据。
- 没有授权或需求表依据时，不得添加 `certified`、`approved`、`official`、`patented` 等认证表达。
- 禁止未经授权使用他店图片、商标、logo 或角色。
