# 设计、文案与提示词

## 设计原则

- 突出卖点，符合北美市场应用场景。
- 图片文案只允许使用需求表中的英文或用户确认的内容。发现拼写、单复数、明显语法或单位格式错误时，只做保持原意的最小修正。
- 图片内不得出现中文。
- 整套图片统一字体家族、色彩关系和图形语言，不统一背景、场景或版式结构。反推专用参考图只供主 Agent 反推允许的版式和场景信息，不得进入生图输入；产品外观只以 manifest 实拍为准。
- 人物年龄、体型、家庭环境、家具尺度、使用方式和审美应符合美国目标市场预期。抱枕、坐垫、床品、家居用品、宠物用品、婴童用品等必须按真实尺寸和使用对象校验比例。
- 需求表或用户明确商品为 `N PC`(例如2PC/4PC等) 时，同一使用场景必须准确展示 `N` 件产品；数量未知时不得推断多件装。
- 主图突出完整产品；副图根据卖点与素材关系选择视觉叙事、构图重心和信息层级。
- 三版必须使用不同的视觉叙事和版式结构；仅移动产品、人物或文字，或者只改变拍摄角度，不算不同版式。
- 主图有文案时，标题必须成为仅次于产品的第二视觉焦点(文案字号足够大)：使用粗体或特粗体展示字体，字号明显大于副标题，且不允许使用纯黑/灰等无颜色倾向的字体颜色；标题色优先使用 VI 或明亮暖色，主图的文案添加白色描边。所有图片的标题字号都应该足够大。
- 仅限主图：主图文字必须直接叠加在背景图或场景图上，文字与背景之间不得增加卡片、底板、胶囊、色块或半透明遮罩；允许文字自身使用描边和轻微投影。
- 全套统一字体家族与色彩关系。
- 非纯场景副图必须明确布局结构、产品区域、文字区域和辅助模块，产品、文案与辅助模块形成完整视觉路径，不得出现无用途的大面积留白；不得为了填充画面新增无依据文案，只能使用需求表已有内容、真实细节特写、尺寸线、色块或场景切片。
- 需求表中要求每个颜色各生成一张场景图或 SKU 图时，本流程每种面料仅生成一个颜色的SKU：优先使用用户指定颜色，其次使用需求表指定颜色，否则使用已锁定的产品实拍基准色；多个实拍颜色无法确定唯一基准时阻塞。
- 同时存在多颜色与多个 PC SKU 时，每个 PC 规格单独规划一个 SKU 图号并准确展示对应件数，所有图号使用上述统一颜色；每个图号仍分别生成 `direct01`、`direct02`、`direct03`。

## 资料与优先级

- 同目录有 VI 手册 / brand guide / logo 规范时，严格遵守其配色、字体、logo 和版式。
- 需求表是需求、参考、文案、尺寸、输出类型 和禁用信息的最高内容依据。
- 需求表与用户口头要求发生冲突时，且处于Plan mode，请向用户提问。
- 必须理解产品尺寸的含义，并用人物、家具、手持、宠物、儿童或实际使用环境校验画面比例。
- 必须识别 WPS `DISPIMG` 单元格中的嵌入图片。

## 颜色规则

**产品颜色展示**

1. 优先使用映射中的产品实拍图颜色。
2. 制作颜色展示副图且有对应面料颜色图或色卡图时，按该依据为产品改色。
3. 没有面料图但需求表或文件名有颜色文字时，按颜色文字改色。

**色块展示**
> 此规则在生成符合条件图片的提示词中体现。

- 其他图片的色块不得显示颜色编号，包括颜色代号、Color ID 和 SKU 色号；普通副图可以保留需求表提供的颜色名字。
- 主图要求添加色块时，色块必须直接叠加在背景图或场景图上，色块组与背景之间不得增加承载卡片、底板或底色；主图与非色号图/定制模板的图中色块上不得显示颜色编号或颜色名字。

**色块素材缺失**

需求表要求放置色块，但没有找到全部颜色编号对应的实际图片时，仅使用已有颜色图占位。

## 提示词编写步骤

首次生图前，按以下顺序完成当前图号的 `direct01`、`direct02`、`direct03` 三版提示词。

1. 显式调用一个全新的 `temu_image_inspector`，只查看映射中的全部产品实拍并返回产品可见事实；反推专用参考图缺失不阻塞，其他依据冲突时先阻塞。
2. 主 Agent 根据产品实拍查看结果锁定三版共有的产品结构、面料、颜色、比例、英文文案、颜色依据和禁止项，不得在版本间改变；指定唯一的主产品实拍为 `edit target` 和产品外观来源。
3. 产品基准锁定后，主 Agent 亲自读取需求表、查看其中全部图片并确定反推专用参考图；主 Agent 同时查看需求表以外的颜色/面料、结构细节、插入或辅助图片并冻结实际生成输入和不使用图片。已确定的反推专用参考图存在时，再逐张形成反推结果并按生成模块分配给各 direct；不存在时自行规划三版。冻结分配或自行规划状态，并写入 `【内部参考反推记录】`。
4. 基于各 direct 的反推结果或自行规划，确定本图的输出类型、单一销售任务、场景和构图；人物只在需求表、图片用途或真实比例校验需要时加入，无依据或无必要时不加入人物。
5. 根据已确定的场景、构图和版式选择其他实际生成输入，逐张记录颜色/面料、结构细节、插入或辅助素材角色，并编排连续的 `Image N`。实拍姿态与目标姿态不同时，同时使用完整产品实拍与侧面/厚度实拍，明确旋转后长边、短边和厚度的方向，只改变姿态，不重新设计产品；实际生成输入记录与内部反推记录不得混排。
6. 按下方字段格式写出三版提示词；每版都明确说明主产品实拍、不可变项、版式结构、产品区域、文字区域和辅助模块，只允许改变当前版本明确指定的场景、构图和版式，不适用字段删除，不得保留说明性占位符。
7. 将 `额外添加的提示词` 中符合条件的，加入到提示词中，如果符合多条则都要加上。
8. 生图前检查三版的不可变项，均为 1:1，英文文案、实际输入角色、真实比例和版式结构完整；不得包含未传入图片的路径、名称、图片编号或引用，也不得包含中文、无依据的产品/颜色/人物/文案/功效信息，或 `generous breathing room`、`generous spacing`、`clean empty background` 等主动制造空白的泛化表述。
9. 定制产品须确认形状能力：未明确支持异型时只允许依据产品尺寸的定制范围定制长/宽/厚，不新增其他异型选项；
10. 无文案时删除文案字段，并且提示词中不允许规定字体。
11. 不允许出现冗长的负面提示词。
12. 如果当前产品有多个颜色/面料，并且需求中要求使用多颜色/面料，但是实拍图只有一种，那么将实拍图和面料/颜色图作为实际生成输入，生成对应的面料/颜色产品。
13. 如果产品有多个颜色/面料，并且需要生成多场景图，每个产品要使用不同的颜色/面料，如果颜色/面料数量小于场景数量则可以使用同颜色/面料。

## 提示词产出格式

提示词描述统一使用中文，图片内文案仍使用英文(如果有的话)。
每张图的三版提示词均按以下九个字段顺序编写；不适用字段删除，不得保留说明性占位符。
无文案时删除文案字段，并且提示词中不允许规定字体。

```text
prompt开始固定提示词: `Amazon US Main & Additional Images`

【图片比例】
1:1正方形构图

【画面目标】
这张图要解决的销售任务：解释功能、展示材质、证明尺寸、突出定制、表现舒适感等。

【产品输入】
只写明实际生成输入：`2560px拍摄图/_manifest.json` 中的产品实拍，以及按需加入的颜色/面料、结构细节、插入或辅助素材。不得填写或上传原始拍摄图路径。将主实拍写为 `Image 1: edit target and sole product appearance source`；其他实拍只补充厚度、底面或局部结构，其他实际输入只承担已声明的角色。必须写明“保留产品结构、面料、颜色和比例”。不要用类别常识重述产品细节，使用实际输入序号代指产品，例如："Image 1 中的产品"。
定制产品还须指明承载已锁定系带数量与位置、滚边数量等结构基准的实拍图编号，并将基准作为验收约束；这些文字不得替代垫图或重新定义产品结构。并且必须将素材中的结构图作为实际生成输入。

【画面构成】
写明版式结构、主体产品位置与占比、场景、背景、道具、文字区域、辅助模块和信息层级；人物只在需求表、图片用途、真实比例校验需要或内部反推确定画面需要人物时加入，不得复制人物身份或相貌。不得保留未分配用途的大面积空区。
除了SKU、明确要求或内部反推确定为白底构图的情况，不要直接在版式/白底上放产品图，产品要与场景结合。`N PC` 商品写明同一场景中的准确产品数量。

【颜色/面料】
不描述或重构产品细节。

【view_image 实际输入记录】
只列出当前 Session 中已执行 view_image 且将实际传给生图工具的图片及角色：
- Image 1: edit target
- Image 2: primary product identity
- Image 3: fabric/material
- Image 4: detail/structure
- Image 5: insert/supporting asset
根据实际情况增减。

【文案】
不得出现中文。

【风格】
整套图统一品牌气质、字体家族、色彩关系和图形语言，不统一背景、场景或版式结构。

【版式/字体与配色】
按需直接写明版式结构、产品区域、文字区域、辅助模块、字体大小与配色(字体与配色的提示词必须整套统一[无衬线体/圆体/衬线体等])。不得使用主动制造空白的泛化表述。
```

`【内部参考反推记录】` 由主 Agent 独立保留，不属于上述提示词。每张反推专用参考图记录绝对路径、分析角色、提取的版式/场景/展示数量，以及商品规格的真实来源；不得写入提示词文件或传给生成、验收 Subagent 和生图工具。
## 额外添加的提示词

> 提示词里的`[]`和其中的内容为变量，根据规定或实际情况来改动

- 当图中有产品出现在场景里时，加入以下固定提示词：

``` prompt
场景充满生活感，布景合适，专业电商摄影风格，专业打光，保持产品的透视角度正确，产品的光影自然的融入场景中
```

- 当图中有坐垫之类的产品出现在应该符合尺寸载体上时，加入以下提示词，将 `[载体]` 替换为实际的载体名字：

    ``` prompt
    产品尺寸与[载体]完美匹配， [载体]上不允许出现空隙
    ```

    - 包括但不限于的情况：
    - 应用情况：长凳垫/九针垫 放在 沙发/飘窗/长凳/长椅 上时
    - 排除情况: 沙发 放在 地面上, 桌布 放在 桌子上。

- 当坐垫产品需要放在沙发或原本已有坐垫的载体上时，加入以下提示词：

    ``` prompt
    产品(产品的名字)替代[载体]原有的坐垫，在产品下方不允许出现[载体]自带的坐垫，产品下方不允许出现[载体]自带的坐垫。
    ```

- 当坐垫产品不支持异型定制，但是需要放在飘窗上时，加入以下提示词：

    ``` prompt
    飘窗的尺寸和形状必须与产品一致，飘窗上方的空间必须为长方形。
    ```

- 当制作的产品为坐垫(长凳垫/九针垫/包含坐垫的套装/其他坐垫)并且坐垫厚度不允许定制时，加入以下提示词：

    ``` prompt
    坐垫的厚度必须与原图一致。
    ```

- 当前有 manifest 产品实拍图输入时，加入以下提示词，将`[Image N]`改为 manifest 记录为实拍图输入的序号，如果传入多张实拍图则需要写上多张图片：

    ```
    [Image N]是本图唯一的产品外观来源。将[Image N]中的同一件实物置入目标画面，不重新设计或替换；产品的轮廓、结构、面料、颜色、比例和细节必须与[Image N]一致。[如果产品是坐垫或者包含坐垫(坐垫/长凳垫/九针垫等)则在此处额外加入一句：`坐垫的厚度必须一致`]。其他实际输入仅按已声明的颜色/面料、结构细节、插入或辅助素材角色使用，不得改变目标产品外观。
    ```

- 当生成非纯场景副图或白底图/SKU时，加入以下提示词：

    ```
    图片版式布局丰富协调，不允许大面积留白。
    ```

## 平台规范

**主图**

- 产品不得被裁切，不得用夸张透视或错误参照物误导尺寸。
- 主图中的产品必须占据足够大的视觉空间。
- 如果内部反推确定为白底构图，且需求中没明确要求带场景或载体，则生成白底图(文案按需加入)。

**副图**

- 如果场景图展示多个场景，并且产品有多种颜色的情况下，场景图中应展示不同颜色的产品。
- 可做场景图、卖点文案、结构说明、尺寸说明、材质细节、定制选项、使用前后对比、颜色选择、SKU 展示或规格展示，信息可以比主图更完整。
- 颜色、图案、尺寸、数量或定制选项必须准确，避免误解实际可选范围和售卖内容。
- 尺寸图必须结合真实产品尺寸和常见参照物，避免把产品做得过大或过小。

**合规限制**

- 禁止无依据的绝对化或误导词，例如 `best`、`#1`、`perfect`、`100% safe`、`guaranteed`、`forever`，除非需求表提供可核验依据且平台允许。
- 禁止医疗、治疗、矫正、疾病改善或功效暗示，除非有明确资质和需求表依据。
- 没有授权或需求表依据时，不得添加 `certified`、`approved`、`official`、`patented` 等认证表达。
- 禁止未经授权使用他店图片、商标、logo 或角色。
