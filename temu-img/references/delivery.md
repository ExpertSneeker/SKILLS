# 交付与终验

## 制作规范

- 所有 TEMU 图片最终尺寸为 `1000*1000`。
- TEMU 不把详情页长图作为本工作流的独立输出类型。需求表中的详情、详情页、SKU、颜色图、规格图和卖点图都按副图处理，除非用户另行指定。
- 产品尺寸单位优先使用美国市场常用的 `inch`；需求表已有明确单位时按需求表执行，图片内表达必须自然、统一、易读。

**路径**

- 最终交付图片：`./output/final`
- 临时检查对比稿：`./output/temp`
- 直接生成图片、来源清单和污染隔离位置：按当前工具适配器或工具自身 skill 执行
- 最终交付不得只留在生图工具默认目录或临时目录
- 在 Windows 中文目录中处理图片或表格时，使用 Unicode 安全的绝对路径和文件 API；不要通过会丢失编码的管道或通配符把中文文件名传给脚本。出现 `????` 路径时，先修复读取方式再继续

**命名**

- 直接生成图：`产品名_图类型_序号_direct01.png`、`direct02.png`、`direct03.png`
- 最终交付图：`产品名_图类型_序号_v01.png`
- 示例：`custom_sofa_cushion_副图_01_v01.png`

## 筛选与临时稿

- 从三版中优先选择产品还原最准、比例最合理、英文文字错误最少、构图最稳定且最符合 TEMU 美国站风格的版本。
- 局部修改或准确英文文字覆盖只能保存到 `./output/temp` 作为检查对比稿。
- 最终交付不得使用本地排版或文字覆盖；直出英文多次重生成仍错误时，跳过该图，不得交付。

## 自我检查清单

- [ ] 所有最终图片尺寸为 `1000*1000`
- [ ] 所有有效 direct 图已保存到当前工具规定的直接生成路径
- [ ] 所有最终交付图已保存到 `./output/final`
- [ ] 如有局部修改或文字覆盖，检查对比稿已保存到 `./output/temp`，最终交付未使用本地排版或文字覆盖
- [ ] 每个未跳过的图型均保留至少 3 个直接图生图版本；如曾中断，已按文件数量、大小和时间戳核对并补齐
- [ ] 当前工具要求的源文件路径、源/目标哈希、尺寸、提示词编号和来源清单均完整
- [ ] 每个直接结果都按当前工具适配器的规则唯一定位，没有猜测来源
- [ ] 所有 direct 图均为当前 TEMU 产品、英文画面和正方形构图；无其他 Session、品牌、语言或产品混入
- [ ] 作废或污染图片未计入三版，并按当前工具规则记录或隔离
- [ ] 产品、面料、颜色、结构、缝线和厚度与产品实拍图一致
- [ ] 颜色展示副图按“实拍图颜色 > 面料颜色图/色卡图 > 颜色文字 > 留白”处理
- [ ] 除需求表或用户明确标注的“定制模板”与“色号图”外，所有色块均无颜色编号；主图如有色块，已直接叠加在背景图或场景图上，色块组与背景之间无承载卡片、底板或底色，且无颜色编号或颜色名字
- [ ] 如使用关键 JPG 参考图，只参考材质、场景、版式或信息层级，没有照搬他人内容
- [ ] 场景中产品大小符合真实尺寸，已用人物、家具、手持、宠物、儿童或使用环境校验
- [ ] 图片内无中文、乱码或机器直译腔
- [ ] 文案与需求表英文一致，仅做必要的最小拼写、语法或单位格式修正
- [ ] 整套图的风格、光线、背景、字体、图标和配色一致
- [ ] 文字无错拼、错字、遮挡或溢出，移动端缩小后仍可读
- [ ] 没有添加需求表未提供的认证、功效、排名、销量、绝对化承诺或价格优惠信息
- [ ] 每个图号由独立单图 Subagent 生成
- [ ] 所有输入参考图均已执行 `view_image`
- [ ] 已记录每张图片的角色
- [ ] 未出现上一张图的版式、文案或场景污染
