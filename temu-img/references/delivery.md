# 直接保存与交付

## 制作规范

- 生成结果保留当前生图工具的原生正方形尺寸，生成后不再统一缩放为 `1000*1000`。
- TEMU 不把详情页长图作为本工作流的独立输出类型。需求表中的详情、详情页、SKU、颜色图、规格图和卖点图都按副图处理，除非用户另行指定。
- 产品尺寸单位优先使用美国市场常用的 `inch`；需求表已有明确单位时按需求表执行，图片内表达必须自然、统一、易读。

**路径**

- ImageGen 直接生成图片和来源清单：`./output/gpt-images-2-direct`
- Seedream 直接生成图片和调用记录：`./output/seedream5-pro-direct`
- 技术失败隔离位置：按当前工具适配器或工具自身 skill 执行
- 生成结果必须保存到上述当前工具的直接生成目录，不得只留在工具全局默认目录或临时目录
- 在 Windows 中文目录中处理图片或表格时，使用 Unicode 安全的绝对路径和文件 API；不要通过会丢失编码的管道或通配符把中文文件名传给脚本。出现 `????` 路径时，先修复读取方式再继续

**命名**

- 直接生成图：`产品名_图类型_序号_direct01.png`、`产品名_图类型_序号_direct02.png`、`产品名_图类型_序号_direct03.png`
- 示例：`custom_sofa_cushion_副图_01_direct01.png`

## 直接保存规则

- `direct01`、`direct02`、`direct03` 生成成功后分别直接保存并标记 `SAVED`，三版全部作为交付结果保留。
- 单版生成 Subagent 返回后，主 Agent 和其他 Agent 均不得查看生成图片；只允许核对文件存在性、可读取性、正方形尺寸、哈希、路径和调用记录。
- 不比较或挑选三版，不创建 `./output/final`，不生成 `_v01`，不做生成后缩放、局部修改、文字覆盖或本地修图。
- 图片内容问题不得触发重新生成；只有文件级技术失败可以按生成模块重试同一 direct 一次。

## 保存完成清单

- [ ] 每个图号的三个 direct 均已保存到当前工具规定的直接生成目录，或已记录技术失败后的缺失项
- [ ] 每个已保存文件可读取、为 1:1 正方形，并有完整且唯一的路径、哈希和调用记录
- [ ] 三版均保留原始 direct 文件名和工具原生尺寸
