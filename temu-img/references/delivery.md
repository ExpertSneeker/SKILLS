# 交付与终验

## 制作规范

- 所有 TEMU 图片最终尺寸为 `1000*1000`。
- TEMU 不把详情页长图作为本工作流的独立输出类型。需求表中的详情、详情页、SKU、颜色图、规格图和卖点图都按副图处理，除非用户另行指定。
- 产品尺寸单位优先使用美国市场常用的 `inch`；需求表已有明确单位时按需求表执行，图片内表达必须自然、统一、易读。

**路径**

- 最终交付图片：`./output/final`
- 临时检查对比稿：`./output/temp`
- 直接生成图片、来源清单和污染隔离位置：按当前工具适配器或工具自身 skill 执行
- 最终交付不得只留在生图工具默认目录或临时目录
- 在 Windows 中文目录中处理图片或表格时，使用 Unicode 安全的绝对路径和文件 API；不要通过会丢失编码的管道或通配符把中文文件名传给脚本。出现 `????` 路径时，先修复读取方式再继续

**命名**

- 直接生成图：`产品名_图类型_序号_direct01.png`、`direct02.png`、`direct03.png`
- 最终交付图：`产品名_图类型_序号_v01.png`
- 示例：`custom_sofa_cushion_副图_01_v01.png`

## FINAL 筛选与门禁

- 只从同一图号三张经独立验收为 `PASS` 的 direct 中选择产品还原最准、比例最合理、英文正确、构图最稳定且最符合 TEMU 美国站风格的版本。
- FINAL 保存为 `1000*1000` 后，须由独立验收 Subagent 复查生成模块 Direct 门禁的全部内容及整套图片的一致性。
- FINAL 验收失败时先改选另一张 `PASS` direct；无合格候选时重新生成。不得本地修补后交付，终验通过前主 Agent 不得输出 `final`。
- 局部修改或准确英文文字覆盖只能保存到 `./output/temp` 作为检查对比稿。
- 最终交付不得使用本地排版或文字覆盖；直出英文多次重生成仍错误时，跳过该图，不得交付。

## FINAL 与整套终验清单

- [ ] FINAL 只从三张 `PASS` direct 中选择，并已保存到 `./output/final`
- [ ] 所有最终图片尺寸为 `1000*1000`
- [ ] FINAL 已由独立验收 Subagent 复查生成模块 Direct 门禁的全部内容
- [ ] 除定制选项对比图可并列展示多个有素材依据的结构状态外，整套图的产品结构、售卖数量、载体适配、风格、光线、背景、字体、图标和配色一致；对比图每个状态分别符合对应素材
- [ ] 文字在移动端缩小后仍可读，且未添加需求表未提供的认证、功效、排名、销量、绝对化承诺或价格优惠信息
- [ ] 主图有文字时，文字直接叠加在背景或场景上，文字与背景之间没有卡片、底板、胶囊、色块或半透明遮罩。
- [ ] 如有局部修改或文字覆盖，检查对比稿仅保存到 `./output/temp`，FINAL 未使用本地排版或文字覆盖
- [ ] FINAL 验收失败时已改选另一张 `PASS` direct；无合格候选时已重新生成，未修补或交付失败版本
- [ ] 每个图号的 `direct01`、`direct02`、`direct03` 分别由全新单版生成 Subagent 串行生成并取得独立验收 `PASS`，整套待办清零且终验通过。
