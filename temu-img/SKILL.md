# TEMU 图片工作流

## 开工前检查

缺一项就先报错，不要硬做或凭空补信息。

- [ ] 有需求表
- [ ] 有产品尺寸
- [ ] `2560px拍摄图/_manifest.json` 存在，且映射中至少有一张产品实拍图
- [ ] 有输出类型：主图 / 副图 / 颜色图 / SKU 图 / 尺寸图 / 卖点图
- [ ] 已确认采用“主 Agent 规划、最多三个单版生成 Subagent 同时调用生图工具、同一图号的每个 direct 串行生成，并由全新验收 Subagent 独立验收；非生成 Subagent 不计入此上限”
- [ ] 已确认 `2560px拍摄图/_manifest.json` 登记的实拍图与其他参考图片都先执行 `view_image`
- [ ] 已检查 VI 手册、产品图、参考图、面料图、色卡图、颜色代号图等素材可读

## 拍摄图输入门禁

- 只有 `2560px拍摄图/_manifest.json` 存在、非空时，才可继续本 Skill。
- 本 Skill 只读取映射中登记的目标文件；禁止读取、查看或传递原始拍摄图路径。
- 本 Skill 后文的“产品实拍图”“产品实拍”“实拍输入”和“产品垫图”均指当前任务 `2560px拍摄图/_manifest.json` 中登记的目标文件，不指原始拍摄图。

## 生图工具选择器

- 当前任务明确指定生图工具时使用指定工具；如果 `references/<工具名>.md` 存在，先完整读取该适配器，否则读取该工具自身 skill。
- `豆包`、`豆包生图`、`Seedream`、`Seedream 5.0 Pro`、`seedream5.0pro` 均指 Seedream 5.0 Pro：完整读取 [seedream.md](references/seedream.md)，并直接运行 `scripts/seedream5_pro.py`。用户明确“用豆包生成”时不得转交其他生图工具。
- 未指定生图工具时使用 `$imagegen`，并完整读取 [imagegen.md](references/imagegen.md)。
- 工具只选择一次，后续统一称“当前生图工具”。

## 设计步骤

严格按以下顺序执行，缺一不可。

1. 规划图片与编写提示词前的步骤
    - 完整读取 [design-and-prompt.md](references/design-and-prompt.md)。
    - 若用户或需求表明确支持定制，或者尺寸为连续可选区间时，完整读取 [custom-product.md](references/custom-product.md)。
    - 产品实拍图只按拍摄图输入门禁处理；其他不可读取的 JPG/JPEG/PNG 参考图片必须先转码或用其他工具打开。
2. 优先读取 `.xlsx/.xls` 需求表中的需求、参考图、英文文案、尺寸、输出类型、颜色/SKU 等信息，并按设计模块处理需求表与平台规范的优先级。
3. 确认 `2560px拍摄图/_manifest.json` 映射非空后，才可查看或规划产品实拍图。
4. 从需求表取得并理解产品尺寸，按人物、家具、手持、宠物、儿童或使用场景校验比例；
5. 按设计模块分别处理产品颜色展示和色块素材缺失，不得凭空编造颜色。
6. 识别 WPS `DISPIMG` 单元格图片，不得漏读嵌入图片。
7. 组织主 Agent、单版生成 Subagent 与独立验收 Subagent、准备输入或开始生成前，完整读取 [generation-workflow.md](references/generation-workflow.md)；首次生图前建立产品/面料基准，确定强制输入、必须保持的颜色、纹理、结构、比例和禁止偏离项。
8. 按生成模块准备映射中的产品实拍垫图、相关参考图和图片角色；首次生图前，按设计模块的提示词编写步骤与九字段格式，完整预写 `direct01`、`direct02`、`direct03` 三版提示词并完成生图前检查；调用前按选择器读取对应适配器或工具自身 skill，再使用当前生图工具进行整图图生图。
9. 每张图片至少生成三次；`direct01`、`direct02`、`direct03` 的提示词必须有明确调整，并保存到当前工具规定的直接生成路径。最多三个单版生成 Subagent 同时调用生图工具；验收、素材读取和其他非生成 Subagent 不计入此上限，也不受本 Skill 额外限制。同一图号的 direct 仍按验收门禁串行推进；“同时生成三张图片”不得合并为一次调用，每个 direct 仍由一个全新 Subagent 调用一次生图工具。
    - 每次生成前按当前工具适配器或自身 skill 建立调用记录，每次只接受可唯一归属本次调用的一张源图。
    - 所有 direct 图必须为正方形；非正方形、来源不明、内容不符或混入其他语言/产品的文件作废，不计入三版。
    - 每张 direct 立即形成包含来源、哈希、尺寸和提示词编号的完整来源记录；当前工具使用共享来源清单时，生成 Subagent 只把记录返回主 Agent，由主 Agent 串行写入。
    - 每个直接生成结果由主 Agent 确认完成来源登记或作废记录后，立即按生成模块的 Direct 门禁由独立验收 Subagent 输出 `PASS` 或 `FAIL`；`PASS` 只推进当前图号任务链，`FAIL` 不计入三版并由全新替补 Subagent 补生成同一缺失序号，其他图号继续执行；未取得三张 `PASS` 前不得进入第 11 步。
10. 当前工具或 Session 中断、超时或未稳定进入下一次生成时，不得标记完成；核对直接生成目录的文件数量、大小和时间戳，从缺失图型及序号继续补齐。
11. 选片、保存 FINAL 或执行 FINAL/整套终验前，完整读取 [delivery.md](references/delivery.md)；按交付模块从三张 `PASS` direct 中选择产品还原、比例、英文、构图和平台风格最准确的一版，局部修改或文字覆盖只保存为临时检查对比稿。
12. 按交付模块完成尺寸、输出类型映射、路径和命名；最终图不得只留在工具默认目录或临时目录。
13. 使用交付模块的 FINAL 与整套终验清单，确认符合需求表、TEMU 平台规范、美国市场风格和本工作流。
