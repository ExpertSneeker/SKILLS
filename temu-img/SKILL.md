# TEMU 图片工作流

## 开工前检查

缺一项就先报错，不要硬做或凭空补信息。

- [ ] 有需求表
- [ ] 有产品尺寸
- [ ] 有产品实拍图
- [ ] 有输出类型：主图 / 副图 / 颜色图 / SKU 图 / 尺寸图 / 卖点图
- [ ] 已确认采用“主 Agent 规划、单图 Subagent 生成”
- [ ] 已确认所有参与图生图的图片都先执行 `view_image`
- [ ] 已检查 VI 手册、产品图、参考图、面料图、色卡图、颜色代号图等素材可读
- [ ] 产品实拍图只读取 JPG/JPEG/PNG；忽略 `.ARW`、`.CR2` 等 RAW，不传给 `view_image` 或当前生图工具；筛选后没有可用实拍图时按缺少实拍图阻塞

## 生图工具选择器

- 当前任务明确指定生图工具时使用指定工具；如果 `references/<工具名>.md` 存在，先完整读取该适配器，否则读取该工具自身 skill。
- 未指定生图工具时使用 `$imagegen`，并完整读取 [imagegen.md](references/imagegen.md)。
- 工具只选择一次，后续统一称“当前生图工具”。

## 设计步骤

严格按以下顺序执行，缺一不可。

1. 规划图片与编写提示词前，完整读取 [design-and-prompt.md](references/design-and-prompt.md)；然后在产品目录查找 VI 手册 / brand guide / logo 规范和产品实拍图。VI 存在时严格遵守；不可读取的 JPG/JPEG/PNG 必须先转码或用其他工具打开，确保正确使用每张参考图片。
2. 优先读取 `.xlsx/.xls` 需求表中的需求、参考、英文文案、尺寸、输出类型、颜色/SKU 和禁用信息，并按设计模块处理需求表与平台规范的优先级。
3. 从需求表取得并理解产品尺寸，按人物、家具、手持、宠物、儿童或使用场景校验比例；
4. 按设计模块分别处理产品颜色展示和色块素材缺失，不得凭空编造颜色。
5. 识别 WPS `DISPIMG` 单元格图片，不得漏读嵌入图片。
6. 组织主 Agent 与单图 Subagent、准备输入或开始生成前，完整读取 [generation-workflow.md](references/generation-workflow.md)；首次生图前建立产品/面料基准，确定强制输入、必须保持的颜色、纹理、结构、比例和禁止偏离项。
7. 按生成模块准备产品实拍垫图、相关参考图和图片角色；首次生图前，按设计模块的提示词编写步骤与九字段格式，完整预写 `direct01`、`direct02`、`direct03` 三版提示词并完成生图前检查；调用前按选择器读取对应适配器或工具自身 skill，再使用当前生图工具进行整图图生图。
8. 每张图片至少生成三次；`direct01`、`direct02`、`direct03` 的提示词必须有明确调整，并保存到当前工具规定的直接生成路径。
8.1 每次生成前按当前工具适配器或自身 skill 建立调用记录，每次只接受可唯一归属本次调用的一张源图。
8.2 所有 direct 图必须为正方形；非正方形、来源不明、内容不符或混入其他语言/产品的文件作废，不计入三版。
8.3 每张有效 direct 图立即写入当前工具规定的来源清单，记录其要求的来源、哈希、尺寸和提示词编号。
9. 当前工具或 Session 中断、超时或未稳定进入下一次生成时，不得标记完成；核对直接生成目录的文件数量、大小和时间戳，从缺失图型及序号继续补齐。
10. 筛选、保存或验收结果前，完整读取 [delivery.md](references/delivery.md)；按交付模块从三版中选择产品还原、比例、英文、构图和平台风格最准确的一版，局部修改或文字覆盖只保存为临时检查对比稿。
11. 按交付模块完成尺寸、输出类型映射、路径和命名；最终图不得只留在工具默认目录或临时目录。
12. 使用交付模块的完整清单终验，确认符合需求表、TEMU 平台规范、美国市场风格和本工作流。
