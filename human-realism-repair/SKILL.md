# 人物结构与真实感修复

核心做法：把人物的头部换成另一个人。为新人物写一段具体的长相描述，让模型据此重新生成头部，得到像真人照片的形象。身体只修有明确错误的地方，其余画面保持不变。每张图出三版，三版提示词各不相同，由三个独立 Subagent 分别生成。

- 默认重新生成整个头部（脸、发型、耳朵、颈部衔接）；用户只说"脸"时，发型沿用原图。
- 性别呈现、人种相关外观和年龄段从原图读取并沿用，用户另有指定时按用户的来。
- 用户只指定身体部位，或要求"同一个人"时，头部保持原样。

## 工具

只用 Codex 内置 `image_gen` 图生图（配合 `$imagegen`），直接在原图上编辑。主 Agent 负责看图、写提示词、保存和验图，生图只由 Subagent 调用。工具或 Subagent 不可用时停止并说明。

接口没有 mask，区域外只能近似保留。用户要求逐像素不变时，先告知这一点。

## 1. 看图

用 `view_image` 打开目标图，记录：

- **原头部：** 占画面的大小、角度（正面／半侧／侧面）、表情；原来的发型和脸型，供新头部避开；性别呈现、人种相关外观、年龄段。
- **身体问题：** 清楚可见的结构错误（肢体连接、关节方向、手指归属、脚踝承重）及其画面位置。看不清、被遮挡或在画外的部位保持原样。

多人图逐人记录。参考图只用来理解效果方向。

## 2. 写三段头部描述

每张图写三段，对应三位不同的人，每一位都要和原图明显不是同一个人。每段以"年龄段、性别呈现、人种相关外观"开头，后面只写当前大小和角度下看得出来的特征：

| 头部情况 | 写什么 | 长度 |
| --- | --- | --- |
| 小（高度不到画面四分之一）或侧脸 | 发型类型、长度、刘海、发色；额头、鼻梁、下巴的轮廓；脸的胖瘦 | 40–80 字 |
| 大，且正面或半侧 | 以上各项，再加眉眼、鼻、唇的形状和颜色 | 100–150 字 |

- 三版的发型分属不同类型（如低马尾、锁骨发、披肩长发、盘发），并且都不同于原图；脸的轮廓也各不相同。
- 写清秀耐看的普通人，五官端正协调，用平实词（略薄、微圆、平缓）描述，让三人的差别落在脸型和发型上。
- 发型干净利落，与人物年龄、服装风格相称，不遮挡商品。

## 3. 冻结三版提示词

`Use case: precise-object-edit`。骨架：

> 把[位置]的头部换成另一个人。[头部描述段]。新的脸和发型与原图明显不同，长相清秀耐看，像生活照里的真人。淡妆：薄透底妆，自然眉形，淡色唇。肤色均匀干净，有细腻的真实肤质纹理，哑光。头部大小和朝向不变，[表情]。[身体问题及修复要求]。其余内容保持不变。

- 修改范围之外的内容，全文只用结尾"其余内容保持不变"这一句带过。场景、服装、物件、文字、构图和光线一律不描述、不列举、不引用原文；保留说明越长，模型越倾向把原图原样返回。
- 全文不超过 250 字，按骨架写，不另加句子。没有身体问题时，把身体那一句整句删掉。
- 三版各用一段头部描述，其余句子一致。头部保持原样的任务，三版改用不同的修复要求写法（分别从关节结构、外轮廓、接触关系入手）。
- 位置只写到能找到人为止：单人图写"图中人物"，多人图写"画面左侧／右侧的人物"并每人一段描述。
- 派发前把三版提示词存为输出目录下的 `…-v01-prompt.txt`、`…-v02-prompt.txt`、`…-v03-prompt.txt`，之后不再改动。

## 4. 派发三个 Subagent

- 同一张图的三版同轮派发，每版一个全新 `human_image_repairer`（`agent_type="human_image_repairer"`、`fork_turns="none"`）。多张图逐张进行。
- 每个 Subagent 只收到三样东西：该版提示词原文、原图绝对路径、版本号。
- 每个 Subagent 调用一次 `image_gen`，返回明确的源文件路径；主 Agent 把它复制到输出目录。
- 某版技术失败或没有返回源路径时，换一个全新 Subagent 重做该版一次；仍失败就如实记录。

## 5. 验图

逐版打开结果，与原图同比例对照。只验收本次涉及的项目，不适用项跳过；逐项标"通过／未通过／无法判断"并写出视觉依据。

1. **头部：** 与原图并排，一眼能看出换了人和发型；三版之间、多人之间也各不相同。正常观看尺度下像真人照片，长相清秀，带淡妆，肤色干净、没有明显的斑点；头部大小和头肩比例与原图一致，颈部衔接、肤色和受光连贯。
2. **身体：** 原问题已改善，且没有新错误（多余肢体、融合、错误关节、补出的隐藏部位）。
3. **其余内容：** 姿势、服装、场景、文字、产品和画幅发生未经允许的明显变化，判未通过；细微重绘差异记录说明。

某版看不出换了人时，换一种发型类型并加大轮廓差异，重写该版提示词，重做一次。其余未通过项只记录。三版都保留并附结论。

## 6. 保存与交付

- 存到 `原图所在目录/人物修复/`，命名 `原文件名-人物修复-v01.实际扩展名` 至 `v03`；重做或再出一轮时版本号顺延。
- 原图需要本地路径，Subagent 看不到会话里的图片；没有路径时先向用户要。
- 交付：三版图片及绝对路径、各版人物设定一句话、验图结论。
