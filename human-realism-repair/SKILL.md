# 人物结构与真实感修复

修复 AI 人物的结构错误、模板脸和假皮肤，目标是自然可信。

默认允许重新生成脸型和五官；性别呈现、人种相关外观、年龄感，以及用户没要求改的内容保持原样。用户明确要求"同一个人"时才锁定五官。

## 工具

只用 Codex 内置 `image_gen` 图生图（配合 `$imagegen`），直接编辑原图，所有修复都通过生成完成。工具不可用时停止并说明。

接口没有 mask，区域外只能近似保留。用户要求逐像素不变时，先告知这一点。

## 1. 检查

用 `view_image` 打开目标图，把问题归类：

| 类别 | 看什么 |
| --- | --- |
| 结构 | 肢体连接、长度、关节方向；手指归属与接触；脚踝与承重；头肩比例、耳颈连接 |
| 面部形态 | 五官是否各自趋向理想形状、面部体积层次、表情牵动 |
| 皮肤 | 蜡感、塑料感、过度平滑（先排除光照、景深、分辨率的影响） |

- 只修清楚可见、有证据的问题；看不清、被遮挡或在画外的部位保持原样。
- 模板脸是形态问题，靠改形态解决；好看和对称属于正常。
- 修复范围以用户指定的为准。没发现问题就报告结论并结束。
- 多人图逐人检查，肢体归属沿关节和衣袖确认，确认不了的保留并报告。
- 参考图只用来理解效果方向。

## 2. 提示词

`Use case: precise-object-edit`（保身份时用 `identity-preserve`）。顺序：问题及位置（用"画面左侧／右侧"）→ 修复要求 → 保留项。

- **面部：** 点名一两处当前图最突出的具体形态，例如眼睑与眼眶的厚度关系、鼻翼到嘴周的过渡、微笑时面颊与嘴角的联动。目标是五官组合有个体差异。
- **头部：** 保留项只锁头部的外部尺度（大小、位置、朝向、头肩比例、颈部长度），内部五官留给模型重组。
- **皮肤：** 细节量匹配年龄、拍摄距离和原光照，少量、低强度、分布不规则。
- **文字：** 看得清的逐字保持，看不清的保持原样。

骨架：

> 修复这张人物图片：[问题及位置]。[修复要求]。保持性别呈现、人种相关外观和年龄感；保持头部大小与位置、头肩比例、颈部长度、朝向、表情含义、视线、姿势、服装、背景、文字、光色、构图和原裁切。皮肤带有与拍摄距离相称的少量自然微差。

## 3. 验图

打开结果，与原图同比例对照。只验收本次涉及的项目，不适用项跳过；逐项标"通过／未通过／无法判断"并写出视觉依据。

1. **保留项：** 对照提示词逐一核对，重点看头部是否变大。关键比例、动作、文字或场景发生未经允许的明显变化，判未通过；细微重绘差异记录说明。
2. **结构：** 原问题已改善，且没有新错误（多余肢体、融合、错误关节、补出的隐藏部位）。
3. **面部：** 改善来自形态变化；只多了斑点或锐度算未通过。多人图各人保持差异。
4. **皮肤：** 无蜡感、假毛孔、噪点、补丁边界。

最多生成两次，用户只要一版时生成一次。保留项通过、只剩一个问题时，在该结果上定向修正；保留项未通过时，回到原图缩小范围。仍不达标就交付候选并说明局限。

## 4. 保存与交付

- 存到 `原图所在目录/人物修复/`，命名 `原文件名-人物修复-v01.实际扩展名`，版本号递增；提示词另存为 `…-v01-prompt.txt`。
- 会话图片没有本地路径时，先问保存位置。
- 交付：图片、实际落盘的绝对路径、改善点、残留问题、验图结论。
