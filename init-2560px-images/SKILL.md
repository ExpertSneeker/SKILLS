# 初始化 2560px 图片

## 执行

在用户明确调用本 Skill 后运行：

```powershell
python <skill-dir>\scripts\prepare_product_photos.py --task-root <任务根目录绝对路径> [--source <原始拍摄图目录绝对路径>]
```

- 未传 `--source` 时，解析任务根目录下的 `产品拍摄原图.lnk`。
- 如果`产品拍摄原图.lnk`不存在，则寻找类似 `产品实拍图`、`拍摄图`等类似目录，如果目录中确实有包含相机原格式与JPG格式，则直接使用，否则向用户确认。
- 只允许脚本读取原始图片；不得对原图执行 `view_image`，也不得把原图交给 Agent 或其他工具。
- 脚本仅递归处理 JPG、JPEG 和 PNG。长边不超过 2560px 时原样复制，超过时修正 EXIF 方向并等比缩放。

- 清单的 `target_root` 为 `"."`，`target_path` 与 `relative_path` 均相对于 `2560px拍摄图`，保留子目录并使用 `/`；原图相关的 `source_*` 字段保持不变。
- 整个 `2560px拍摄图` 连同清单和看图缓存可直接复制复用，无需重新初始化。读取时以清单所在目录解析目标绝对路径，目标不得越出该目录；命令完成信息仍显示清单的绝对路径。

### 必须等待命令真正结束

初始化可能超过 10 秒。调用命令后，只有拿到最终结果才算执行完成：

- 如果执行工具返回 `session_id` 或显示命令仍在运行，必须使用同一会话持续轮询（`write_stdin`），直到进程结束并获得最终 `exit_code`。
- 中间的 `Script completed`、空输出、部分图片或 `_prepare.lock` 都不代表初始化完成；在进程结束前不得检查 `_manifest.json`，也不得结束任务。
- 最终成功输出应包含 `prepared=... reused=... manifest=...`，且 `exit_code` 为 `0`。如果命令仍在运行，继续等待，不要启动下一条校验命令。

## 成功条件

命令最终结束后，使用任务根目录拼接出的绝对路径
`<任务根目录>\2560px拍摄图\_manifest.json` 进行校验，不要只依赖当前 Shell 的相对工作目录。

仅当命令最终返回零，且该 `_manifest.json` 存在并至少登记一张图片时继续任务。命令失败、清单缺失或清单为空时停止，不得绕过脚本直接使用原图。
