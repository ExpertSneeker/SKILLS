# Seedream 5.0 Pro 生图流程测试

测试日期：2026-07-25（UTC+08:00）

## 调用契约

- 服务：火山方舟
- 接口：`POST https://ark.cn-beijing.volces.com/api/v3/images/generations`
- 模型：`doubao-seedream-5-0-pro-260628`
- 鉴权：`Authorization: Bearer $ARK_API_KEY`
- 输出：`size: "1K"`、`output_format: "png"`、`response_format: "url"`、`watermark: false`
- 提示词优化：`optimize_prompt_options.mode: "standard"`
- 1K 正方形实测输出：`1024x1024`

纯文生图不传 `image`。多参考图使用有序数组：

```json
{
  "image": [
    "data:image/png;base64,<图1>",
    "data:image/png;base64,<图2>"
  ]
}
```

提示词中的“图 1”“图 2”与数组顺序对应。调用记录只保存文件角色、路径、尺寸、字节数和 SHA-256，不保存 Base64 本体。

## 加入 temu-img 的最小适配要求

1. 调用前创建记录并持久化 `call_id`、提示词编号、输入图角色、SHA-256、尺寸、请求参数和 `submitted_at`。
2. 文生图省略 `image`；图生图用 URL、单个 Data URI 或有序 Data URI 数组。所有输入图在调用前执行 `view_image`。
3. POST 返回后立即记录 `completed_at` 和端到端毫秒数；下载另计时。
4. 方舟返回 URL 仅保留 24 小时，成功后必须立即下载到直接生成目录并计算 SHA-256。
5. 校验 `1024x1024`、PNG、文件非空、主体数量、产品或动物身份、文字准确性和水印。
6. 请求结果不确定时不要自动重发；先核对调用记录与输出目录，避免重复扣费和来源不明。
7. 失败修正优先使用“失败图作为编辑目标 + 原始基准图作为身份参考”的定向编辑，避免整图重做导致文字和版式漂移。

官方限制中与适配器直接相关的部分：最多 10 张参考图；单图不超过 30 MB；输入支持 URL 或小写 MIME 的 Data URI；输出 URL 保存 24 小时；`standard` 质量优先，`fast` 时延优先。
