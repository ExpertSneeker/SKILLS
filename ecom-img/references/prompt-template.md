# 提示词模板

写完整提示词时使用本文件；仅规划的未核实字段须在草案外标出，不作为可执行任务包。来源和查看记录按 [输入合同](inputs.md) 单独保留；定稿前由 [生成预检](generation-workflow.md#生成前预检) 统一核对。

提示词描述统一使用中文，图片内文案使用命中平台规范与需求表共同冻结的语言（如果有文案）。
每张图的三版提示词均按以下九个字段顺序编写；不适用字段删除，不得保留说明性占位符。字段用于组织要求，不是生图工具的特殊语法。
无文案时删除 `【文案】` 和 `【字体与配色】`，并且提示词中不允许规定字体或文字配色。
`【图片比例】`只控制画面构图，不要求生成文件的像素宽高严格匹配；同一图号的三个 direct 必须使用相同的目标构图比例。
命中平台规范定义了固定提示词前缀时，将其逐字放在首个字段之前；平台未定义前缀时直接从首个字段开始。定稿提示词不得出现该选择过程。

每项要求只在负责该内容的字段中完整表述：输入角色在 `【产品输入】`，产品保真与修改边界在 `【修改与保持】`，空间关系在 `【画面构成】`，色块映射和权限在 `【颜色/面料】`，准确文字在 `【文案】`，非文字视觉语言在 `【风格】`，文字样式在 `【字体与配色】`。不同字段可引用同一 `Image N` 或区域名，不重复整段约束。每个 direct 的正文仍须独立完整，不以“同上”或另一版提示词代替。

```text
【图片比例】
按命中平台规范和当前图号的交付类型写入唯一最终构图比例；不保留选择说明或其他候选比例。

【画面目标】
用一句话写明交付画面、单一销售任务和核心卖点，如产品使用场景、材质细节或尺寸说明；具体承载卖点的动作与视觉元素放在【画面构成】。

【产品输入】
按当前 direct 的实际输入顺序，只列连续的 Image N、角色和用途，不写路径、查看记录或素材选择过程。实际产品输入仍只能来自 manifest 登记的目标文件。目标画面出现产品时，唯一底图写为“Image 1 = edit target，当前画面唯一可编辑产品底图”；其他实拍按实际用途标为 primary product identity 或 detail/structure，只补充身份、厚度、底面、局部结构或按压姿态。其他输入标明 target color authority 或 insert/supporting asset；色块的具体映射写入【颜色/面料】。其他实际输入不得成为第二张可编辑产品底图。
定制产品注明承载已锁定结构基准（系带数量与位置、滚边数量等）的实拍 Image N；仅在已确认的定制项确需补充时加入结构参考素材，并声明其 Image N 及用途；采用实拍图风格时另声明提供面料表现的当前产品实拍 Image N，同一实拍兼具多种用途时不重复传入。目标画面不出现产品时不设置 edit target；没有实际输入时删除本字段。

【修改与保持】
目标画面出现产品时，用实际输入编号明确：将 Image 1 中的产品置入目标画面，不重新设计或替换；保持实拍中的产品身份、结构、纹理、光泽、比例和细节。其他实拍只按已声明的角色补充对应属性，不替换目标产品。不得以类别常识或主观视觉判断重述产品细节；除非用户、需求表文字或已声明的结构标注素材明确给出，形状、轮廓、截面和厚薄关系不得被命名、推断或重述，手持、按压、弯折、斜放和透视只表示姿态。
逐项写明当前方案实际需要的变化，如背景、摆放位置、产品姿态、与场景匹配的光照、依据【颜色/面料】执行的颜色校正或改色，以及已确认的定制项及范围；定制项以冻结的结构基准为依据，只改变明确允许的属性，其他属性保持实拍。场景置入不使用“其他一切不变”锁住原照片背景、人物或光线，也不允许借姿态或光照调整改变产品结构、纹理与光泽特征。
将本图适用的尺寸、人物替换、载体适配、坐垫厚度和定制结构保持约束完整写入此字段，不再在末尾追加。定制选项借用结构参考素材时，按实际 Image N 与区域名限定保留的结构和样式，面料区域的材质按定制规则“可定制项参考素材”与【颜色/面料】呈现。真实尺寸仅用于比例校验；需要显式标注时，按尺寸图规则将准确标注同时列入【文案】，其位置与尺寸线关系写入【画面构成】。目标画面不出现产品时，仅保留实际适用的保持或展示边界；没有适用项时删除本字段。

【画面构成】
写明版式结构、主体产品位置与占比、场景、背景、道具、文字区域、辅助模块和信息层级；明确承载核心卖点的场景、使用动作、产品状态、道具关系、对比或真实细节等非文字视觉元素，使画面能表达销售任务。文案、Icon 和文字标签不得作为卖点的唯一表达载体，必须配合视觉元素。不得保留未分配用途的大面积空区。
除了SKU、明确要求或内部反推确定为白底构图的情况，不要直接在版式/白底上放产品图，产品要与场景结合。`N PC` 商品写明每个使用场景中的准确产品数量；多场景画面逐区绑定场景、产品、件数和颜色映射中的区域名，每个 direct 同画面保留所有要求的场景。
有人物时明确身体取景范围、与产品的相对尺度、使用姿态及接触部位；视线影响动作表达时写明视线方向，不只写“自然使用产品”。只描述当前方案所需动作，不新增未经核实的承重、回弹或功效表现。无文案图在本字段按平台要求明确画面无文字；有文案时仅定义文字区域，具体文字与逐条位置绑定放在【文案】。

【颜色/面料】
逐项指定各色块的 Image N 及对应的画面区域、产品/部位最终颜色或色块展示用途。无论是否改色，最终产品颜色只以已声明的对应色块为准，不引用未传入的原色色块。色块只控制颜色，不改变面料、纹理、光泽、结构、比例、细节或文字视觉基准；不得用色块重构产品。未要求展示色块时，明确色块不出现在成图中；明确要求展示时，仅将指定色块作为可见元素，其位置写入【画面构成】，颜色名字或编号仅按本图适用规则列入【文案】。
定制选项借用结构参考素材并采用实拍图风格时，另逐项绑定面料区域与对应的当前产品实拍 Image N，明确其材质、纹理、质感和光泽以该实拍为准；只引用已选实际输入，不扩展到其他区域。

【文案】
逐字写入主 Agent 按冻结语言确定的全部新增可见文字，包括标题、副标题、卖点小标题及对应正文、Icon 下方正文，以及适用的尺寸标注或颜色标签。每条按“层级/用途：\"准确文字\"；位置：已定义区域内的具体位置；出现次数：明确次数”编写；默认每条一次，明确要求重复时写出次数与各位置。主标题搭配副标题、卖点小标题搭配简短正文（命中平台禁止补全层级时除外）。保留冻结的大小写、标点、数字和单位；不让生图工具自行拟写、补全或翻译，不混入其他语言。明确“仅生成清单列出的新增文字，不添加其他文字”；产品原有标签或 Logo 按已确认的产品保真与品牌资产规则处理，不能借此清除或改写。

【风格】
具体写明当前 direct 所采用的视觉风格、色调与色彩、图形语言，保留整套视觉语言基准的核心特征，并可结合当前场景和构图调整措辞与细节；不得只写“与整套统一”，不得写入平台、图片比例、产品规格。要求摄影效果时明确写实摄影，并按当前方案写明光源方向、软硬、色温倾向及接触阴影、反射与环境的关系，不用“高级感”“专业打光”等词代替可见要求。纹理与光泽的具体表现必须有实拍依据，不新增材质细节。整套图不统一背景、场景或版式结构。

【字体与配色】
仅含文案时使用。写明当前 direct 所采用的文字视觉基准，包括字体家族、主标题/副标题/正文的大小层级与字重、各层级颜色（名称与 HEX 值）、描边和投影规则；保持整套的核心字体、层级和配色关系，但可为背景对比度做必要的局部适配，不得只写“与整套统一”，也不得仅因产品色块或产品颜色而重新设计整套文字风格。不重复产品布局、区域占比或文案内容。
```
