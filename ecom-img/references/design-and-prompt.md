# 设计、文案与提示词

## 设计原则

- 突出卖点；场景、人物和审美应符合命中平台文件明确的目标站点或需求表明确的目标市场。
- 图片文案优先使用需求表中与已冻结语言一致的现成文案或用户确认的内容；没有现成文案时，可依据当前图号的销售任务和已核实的产品事实，用已冻结语言拟写简短文案。需求表与反推专用参考图均未提供所需正文或副标题时，补写宽泛、简短的介绍性说明，不写具体数值、规格、认证等可追责信息。不得新增未经确认的规格、认证或绝对化表述。发现拼写、单复数、明显语法或单位格式错误时，只做保持原意的最小修正。
- 当前图片同时为非 SKU、非白底且非纯场景图，分配给当前 direct 的反推专用参考图采用标题式信息层级，并且需求表未明确本图无文案时，加入标题和副标题。反推专用参考图只决定是否采用标题式信息层级，不得作为未经核实的产品事实来源。
- 只要图片中出现主标题，就必须同时加入简短副标题；需求表或反推专用参考图只提供主标题时，按本节文案来源规则补写副标题。
- 同一任务的整套图片应保持已冻结的视觉风格、色调与色彩关系、字体家族、文字配色关系和图形语言整体一致，不统一背景、场景或版式结构。整套所有图号及其 `direct01`、`direct02`、`direct03` 以同一整套视觉语言基准为主要参考；各版可结合已规划的场景、视觉叙事、构图和版式做有限适配，但不得偏离其核心视觉特征。
- 整套首个含文案图号写提示词前，从整套视觉语言基准中确定文字视觉基准。基准应明确字体家族、主标题/副标题/正文字重、各层级文字颜色（颜色名称与 HEX 值）、描边和投影规则；后续含文案图号保持其核心字体、层级和配色关系，可为当前背景对比度、场景和版式做必要的局部适配，不得随意重选整套字体或文字配色。反推专用参考图只供主 Agent 反推允许的版式、文案、Icon、场景和卖点视觉叙事信息，不得进入生图输入；产品外观只以 manifest 实拍为准。
- 人物年龄、体型、家庭环境、家具尺度、使用方式和审美应符合已冻结的目标市场预期。抱枕、坐垫、床品、家居用品、宠物用品、婴童用品等必须按真实尺寸和使用对象校验比例，场景中如果出现人物，则人物必须与产品有接触或者互动/使用产品，而不是当背景板。
- 需求表或用户明确商品为 `N PC`(例如2PC/4PC等) 时，同一使用场景必须准确展示 `N` 件产品(海绵除外,根据需求进行展示或者用填充好的坐垫进行展示)；数量未知时不得推断多件装。
- 主图突出完整产品；副图根据卖点与素材关系选择视觉叙事、构图重心和信息层级。
- 三版必须使用不同的视觉叙事和版式结构；仅移动产品、人物或文字，或者只改变拍摄角度，不算不同版式。
- 每个 direct 都必须独立、完整满足当前图号的明确要求；三版差异化只能调整未被需求限定的表达方式，不得将同一图号的要求拆分到不同 direct 后合计满足。需求规定的场景、展示项目、数量、对应关系及同画面组合要求均须逐版保留；“多场景”“对比”“步骤”“多选项”等要求，应在每个 direct 的同一张画面内完整表达，除非用户或需求表明确要求拆图。
- 主图有文案时，标题必须成为仅次于产品的第二视觉焦点(文案字号足够大)：主标题字重使用整套文字视觉基准中冻结的值；仅当 `./DESIGN.md`、VI、需求表和用户均未指定主标题字重时，才由主 Agent 在冻结基准时默认使用粗体或特粗体。字号明显大于副标题，标题色使用该基准中冻结的颜色；仅当上述四级来源均未指定标题色而由主 Agent 确定时，不允许选择纯黑/灰等无颜色倾向的颜色。描边使用整套文字视觉基准中按同一优先级冻结的规则；仅当上述四级来源均未指定描边时，才由主 Agent 按命中平台文件规定的默认值冻结，平台文件未规定默认值时冻结为无描边。所有图片的标题字号都应该足够大。
- 仅限主图：主图文字必须直接叠加在背景图或场景图上，文字与背景之间不得增加卡片、底板、胶囊、色块或半透明遮罩；允许文字自身使用描边和轻微投影。
- 非纯场景副图必须明确布局结构、产品区域、文字区域和辅助模块，产品、文案与辅助模块形成完整视觉路径，不得出现无用途的大面积留白；不得为了填充画面新增无依据文案。文案须遵守本节的来源规则，其余空间只能使用真实细节特写、尺寸线、色块或场景切片等有依据的内容。
- 图中每个卖点小标题都必须搭配简短正文；细节/卖点/放大特写的卡片、气泡以及 Icon 下方的卖点均适用，正文不要过长。
- 需求表中要求每个颜色各生成一张场景图或 SKU 图时，本流程每种面料仅生成一个颜色的SKU：优先使用用户指定颜色，其次使用需求表指定颜色，否则使用已锁定的产品实拍基准色；多个实拍颜色无法确定唯一基准时阻塞。
- 同时存在多颜色与多个 PC SKU 时，每个 PC 规格单独规划一个 SKU 图号并准确展示对应件数，所有图号使用上述统一颜色；每个图号仍分别生成 `direct01`、`direct02`、`direct03`。
- 当商品为海绵、当前图号为纯场景图/多场景图、用户和需求表均未明确要求露出海绵，且分配给当前 direct 的反推专用参考图不存在或未露出海绵时，只将是否露出海绵作为场景展示方式，不提取参考图中的产品外观；在提示词中按已确认的真实尺寸和用途展示海绵填充后的坐垫使用效果，不直接露出海绵商品，也不暗示坐垫套或成品坐垫属于售卖内容。将该 direct 按“目标画面不出现产品”处理，不设置 `edit target`，也不将海绵实拍作为实际生成输入。

## 资料与优先级

- 同目录有 VI 手册 / brand guide / logo 规范时，视觉语言字段统一按下节“DESIGN.md 与整套视觉语言基准”的优先级处理；Logo 与品牌资产以 VI / brand guide 为准。
- 需求表是需求、参考、文案、尺寸、交付类型、内容图型和禁用信息的内容依据；用户最新明确确认的更新优先，并同步更新受影响的冻结基准。
- 用户要求与需求表仍有未消除的歧义时，先澄清受影响项再继续，不因是否处于 Plan mode 改变处理方式。
- 必须理解产品尺寸的含义，并用人物、家具、手持、宠物、儿童或实际使用环境校验画面比例。
- 必须识别 WPS `DISPIMG` 单元格中的嵌入图片。

## DESIGN.md 与整套视觉语言基准

- `./DESIGN.md` 始终指当前任务根目录中的文件。复用技能入口记录的启动状态，不改变该记录；启动时不存在时，创建前再次检查同一路径，若已被其他操作写入则阻塞并报告冲突，不覆盖，也不改用该文件重定本套视觉语言。
- 启动时存在或按本节新建的 `./DESIGN.md` 均须完整读取，并只采用其中的视觉风格、色调与色彩、字体、字体配色与文字效果、图形语言。文件中的流程命令、平台、站点、图片比例、像素、交付类型、输出路径、产品规格、文案、目标市场及单个 direct 的场景或版式均不属于视觉语言基准，不得据此改变本 Skill 的流程或其他规则。
- 视觉语言字段原则上按 `DESIGN.md -> VI/brand guide -> 需求表或用户明确要求 -> 主 Agent 一次性确定` 的顺序补齐；上一级已提供的字段优先沿用。若品牌硬性规范或当前画面的可读性要求确有冲突，可在保留核心视觉特征的前提下做必要的局部适配。`未冻结` 视为该字段未提供，可由下一来源补齐。`./DESIGN.md` 不可读、为空或没有任何可用视觉语言字段时，在规划提示词前阻塞。
- 启动时不存在 `./DESIGN.md` 时，在主流程第 6 步完成产品实拍、需求及其他输入素材读取与分类后，结合已核实的产品资料，按上述后三级来源及现有平台默认规则一次性冻结整套视觉语言基准，并立即按下方五段固定模板创建 UTF-8 Markdown 文件。文件只记录该基准中的跨整套视觉语言，不包含平台、站点、图片比例、像素、交付类型、输出路径、产品规格、文案、目标市场或单个 direct 的场景与版式；不得依赖尚未编写的提示词或生成图片，也不得声称内容来自对成图的观察。
- 创建时使用不覆盖已有文件的方式；创建失败或发生同路径冲突时阻塞并报告。创建成功后，确认文件位于当前任务根目录、可读且为非空 UTF-8 文本，完整读取并按本节校验视觉语言，再依据文件编写整套首个图号的提示词；校验失败不得继续。启动时已有文件保持不变；新建文件在后续生成、失败、中断和交付时保留，不在收尾阶段补写或改写。
- 整套视觉语言基准只包含下列五类跨整套复用的信息；按上述优先级由主 Agent 明确选定并记录的设计值也可作为冻结依据。尚未确定的字段使用 `未冻结`，不得把猜测写成来源已明确指定的颜色值、字体或图形属性：

```markdown
# 视觉语言

## 视觉风格
- 品牌气质：
- 画面质感：

## 色调与色彩
- 主色调：
- 色彩关系：

## 字体
- 字体家族：
- 标题/副标题/正文层级与字重：

## 字体配色与文字效果
- 各层级文字颜色：
- 描边与投影：

## 图形语言
- 图标与辅助图形：
- 线条、圆角与装饰：
```

- 定稿提示词的 `【风格】` 应具体体现整套视觉语言基准中的视觉风格、色调与色彩、图形语言，不得只写“与整套统一”，可按当前 direct 的表达需要调整措辞和细节。含文案图号另在 `【字体与配色】` 中写明所采用的字体、字体配色与文字效果，并保持核心关系一致；无文案图号不得在提示词中规定字体或文字配色。

## 颜色规则

**产品颜色展示**

1. 先按当前 direct 的场景、构图和版式选择 `edit target` 与确实需要的其他实拍，再根据成图中的产品最终颜色选择准确色块，并纳入需求明确要求展示的其他色块；不要求实拍原色配对或原色色块来源登记。
2. 未要求改色时，使用产品保持的颜色对应色块校正实拍拍摄色差；产品结构、纹理和光泽以实拍为准。
3. 要求改色时，只使用改色后的目标色块决定最终颜色，不为实拍原色另传色块。
4. 产品最终颜色所需色块缺失时阻塞当前 direct；要求改色但缺少目标色块时阻塞当前图号。原色色块缺失不阻塞；不得根据实拍观感、近似色或颜色文字猜色。纯展示色块缺失按下方“色块素材缺失”处理。
5. 相同的最终颜色可以共用一张对应色块，实际输入去重后只传一次，并记录各色块对应的成图产品/部位或展示用途。
6. 色块默认只作为产品颜色依据，不得改变文字的视觉基准，也不得作为可见元素生成；只有需求明确要求展示色块时才在画面中呈现。

**色块展示**
> 此规则在生成符合条件图片的提示词中体现。

- 普通图片的色块不得显示颜色编号，包括颜色代号、Color ID 和 SKU 色号；普通副图可以保留需求表提供的颜色名字。明确要求的色号图或定制模板按定制模块的专用规则执行。
- 主图要求添加色块时，色块必须直接叠加在背景图或场景图上，色块组与背景之间不得增加承载卡片、底板或底色；主图色块不得显示颜色编号或颜色名字。

**色块素材缺失**

需求表要求放置色块，但没有找到全部颜色编号对应的实际图片时，仅使用已有颜色图占位。

## 提示词编写步骤

首次生图前，按以下顺序完成当前图号的 `direct01`、`direct02`、`direct03` 三版提示词。

整套首个图号完成资料读取后、写三版提示词前，必须先完成本文件规定的 `./DESIGN.md` 创建（启动时不存在）、校验与完整读取，并依据文件确定整套视觉语言基准；后续图号以该基准保持核心视觉特征一致，可按各图号的场景、构图和可读性做有限适配。整套首个含文案图号另确定文字视觉基准，后续含文案图号沿用其核心字体、层级和配色关系；无文案图号不得在提示词中使用字体或文字配色字段。

1. 复用入口按 [产品实拍查看缓存规则](../SKILL.md#产品实拍查看缓存跨次运行)取得的当前 manifest 完整合并结果，包括逐张产品可见事实、完整度、视角、主体裁切/遮挡情况和整体三维结构清晰度；仅新增、变化或记录缺失项交由全新 inspector 补看，全部命中时不派发，产品资料未变化时不按图号重复派发。反推专用参考图缺失不阻塞，其他依据冲突时先阻塞。
2. 主 Agent 根据全部产品实拍的查看结果锁定产品真实性底线：产品身份、轮廓、结构、纹理、比例、实拍基准色和禁止偏离项。除非用户、需求表文字或已声明的结构标注素材明确给出，产品形状、轮廓、截面和厚薄关系不得在产品真实性底线或生成提示词中被命名、推断或重述；只用实际输入的 `Image N` 指代并要求保持实拍。手持、按压、弯折、斜放和透视只表示姿态，不得据此定义固定几何结构。
3. 主 Agent 复用已读取的需求表文字、尺寸、售卖数量、交付类型、内容图型、颜色/面料要求、现成文案和输入图片分类；只补查新增、变化或尚未查看的输入素材，排除生成结果。分类仍为反推专用参考图、颜色/面料依据、结构细节、插入或辅助素材，或者不使用。
4. 根据需求表、已核实素材和命中平台规范确定当前图号的交付类型、内容图型、目标构图比例、单一销售任务、真实尺寸、售卖数量、定制能力、文案语言、单位和颜色/面料要求。定制产品须确认形状能力：未明确支持异型时保持已确认的产品轮廓，长、宽、厚只调整已确认可定制的项及其范围，不新增异型选项。
5. 逐张分析已确定的反推专用参考图，只提取允许的版式结构、区域比例、场景、背景、道具、光线、视觉层级、展示数量、图片表达的卖点意图、体现卖点的场景/动作/产品状态/道具关系/对比/真实细节特写等视觉元素(如果没有则不提取，不要写“无xx”)，以及现成文案和标题/副标题信息层级。反推的卖点作为视觉叙事候选；不符合当前产品的功能、结构、功效及其视觉元素不得保留。根据当前图号的销售任务将反推结果分配给各 direct；没有反推专用参考图时，依据销售任务自行规划三版。将分配、自行规划、卖点取舍写入 `【内部参考反推记录】`。
6. 基于销售任务和各 direct 的反推结果或自行规划，确定三版各自的场景、视觉叙事、构图和版式；每个 direct 都必须通过符合当前产品的场景、使用动作、产品状态、道具关系、对比或真实细节等视觉元素表达销售任务，即使去掉全部文案仍能理解核心卖点。文案、Icon 和文字标签只用于强化，不得成为卖点的唯一表达载体。人物只在需求表、图片用途、真实比例校验、经确认的卖点视觉表达需要或反推结果要求时加入，无依据时不加入人物。
7. 按设计原则和命中平台规范确定当前图号的完整文案。先使用需求表或用户确认的、与冻结语言一致的文案；缺失时由主 Agent 根据销售任务和已核实产品事实拟写。反推专用参考图采用标题式信息层级时按设计原则决定标题和副标题，不得让生图工具自行拟写或补全。
8. 根据当前图号的颜色/面料要求和三版规划，分别为每个 direct 选择实际生成输入。只要当前 direct 的目标画面出现产品，就必须先从 manifest 产品实拍中唯一指定一张完整、无遮挡、整体三维结构清晰且最符合该版产品姿态、视角和构图需求的图片作为该 direct 的 `edit target`，再确定确实需要的其他实拍；三个 direct 可以选择同一路径，也可以分别选择不同路径，不得为了统一而强制复用。其他产品实拍只能承担 `primary product identity`、侧面、厚度、底面或局部结构补充角色，不得再标记为 `edit target`。实拍全部选定后，按该 direct 的产品最终颜色与明确的色块展示需求选择色块，色块去重后，与实拍及其他必需素材一起编排为该 direct 独立、连续的 `Image N`。记录各色块与成图产品/部位及展示用途的对应关系，以及结构细节、插入或辅助素材角色；实际生成输入记录与内部反推记录不得混排。
    - 当前 direct 的目标画面不出现产品时，不设置 `edit target`，也不传入无用途的产品实拍。
    - 无论目标构图最终展示完整产品还是产品局部，`edit target` 都必须先排除主体被裁切、关键结构被遮挡或因视角过平导致整体结构难以判断的图片；优先选择能清晰呈现产品整体轮廓、顶面、侧面、厚度及前后纵深关系的斜俯视三分之四视角（约 30°–45°）。没有该视角时，选择能最清晰、完整呈现产品三维结构的其他合格视角；没有任何合格实拍时阻塞当前 direct。局部或裁切实拍只能作为 `detail/structure` 等补充输入，不能成为 `edit target`；目标构图需要其局部细节时，从完整 `edit target` 构成产品主体，并按需用局部实拍补充该细节。
    - 实拍姿态与目标姿态不同时，在符合上一条完整度和三维结构清晰度要求的候选中，优先选择最接近目标姿态的完整产品实拍作为该 direct 的 `edit target`，并按需加入侧面或厚度实拍；明确旋转后只改变姿态，不重新设计产品。
    - 产品最终颜色所需色块缺失时阻塞当前 direct；不得根据照片观感或颜色文字猜测。实拍原色色块缺失不阻塞，也不因此改选不适合构图的实拍。
    - 多张实拍仅用于补充结构、成图产品最终统一为一种颜色时，只需该最终颜色色块；成图有多个产品颜色或额外色块展示需求时，传入各自对应的色块，相同色块去重。
    - 实拍图只有一种颜色/面料，但需求要求生成其他颜色/面料时，将目标色块作为实际生成输入，不额外传入实拍原色色块；没有目标色块时阻塞当前图号。
    - 同一图号的 `direct01`、`direct02`、`direct03` 必须使用相同的目标颜色/面料和已冻结文案。多个独立场景图号有多种颜色/面料可用时，优先在不同图号间分配不同颜色/面料；数量不足时允许复用。
    - 同一张多场景图要出现多个产品，且产品有不同的面料/颜色/印花时，每个场景优先使用不同的颜色/面料/印花；数量不足时允许复用。
9. 冻结三版共同基准：平台、交付类型、产品真实性底线、当前图号的销售任务与核心卖点、目标构图比例、文案语言、单位、尺寸、售卖数量、定制能力、目标颜色/面料、目标色块、完整文案和整套视觉语言基准；当前图号含文案时，还须确定整套文字视觉基准。另行冻结每个 direct 自己的 `edit target`、其他已选实拍、各色块与成图产品最终颜色及展示用途的映射、其他实际生成输入及角色。`edit target` 路径不属于三版共同基准，不要求三版相同；不同底图视角不得导致产品身份或共同事实改变。三版可按各自已规划的场景、视觉叙事、构图和版式对视觉语言细节做有限适配，但不得改变平台、交付类型、销售任务、核心卖点、目标构图比例、文案语言、单位或偏离整套视觉语言基准的核心特征；含文案时应保持文字视觉基准的核心字体、层级和配色关系。
10. 按下方字段格式写出三版提示词；每版都明确说明该 direct 自己的 `edit target`、共同基准和其他实际输入角色。产品保持项与允许变化写入 `【修改与保持】`，版式结构、产品区域、文字区域和辅助模块统一写入 `【画面构成】`。每版必须在 `【风格】` 中具体体现整套视觉语言基准的非文字字段，可根据当前 direct 调整措辞和细节；含文案时，在 `【文案】` 中逐条绑定准确文字、层级、位置和出现次数，在 `【字体与配色】` 中写明文字视觉基准及必要的局部适配。不适用字段删除，不得保留说明性占位符。
11. 逐版判断 `额外添加的提示词` 中人物、载体、尺寸、坐垫厚度等条件规则是否适用，将全部适用内容归入对应字段；同一约束在该版正文中完整表达一次，不再在末尾追加重复段落。合并不得省略适用条件、保持项或例外；内部预检逐项映射到最终提示词中的对应原句。规则只存在于本文、内部记录或派发说明中不算已加入。
12. 生图前检查三版均已明确并使用当前图号冻结的同一平台、交付类型、目标构图比例、文案语言、单位和整套视觉语言基准；文案、实际输入角色、真实比例和版式结构完整，并分别写明能够表达核心卖点的视觉元素。逐版核对 `【风格】` 是否保留整套基准的核心特征，并确认局部适配服务于当前场景、构图或可读性；含文案时，核对 `【字体与配色】` 是否保持文字视觉基准的核心字体、层级和配色关系，文案清单是否完整、位置是否对应画面区域；无文案时删除文案和字体字段并按平台要求写明无文字。正文只包含画面要求及实际输入的编号、角色与用途；路径、查看记录、来源追踪和调用参数留在任务包中。提示词不得包含平台选择说明、候选比例、未传入图片的名称/图片编号或引用，不得包含不符合冻结语言的文案、无依据的产品、颜色、人物、文案或功效信息，不得出现冗长的负面提示词，也不得使用 `generous breathing room`、`generous spacing`、`clean empty background` 等主动制造空白的泛化表述。

## 提示词产出格式

提示词描述统一使用中文，图片内文案使用命中平台规范与需求表共同冻结的语言（如果有文案）。
每张图的三版提示词均按以下九个字段顺序编写；不适用字段删除，不得保留说明性占位符。字段用于组织要求，不是生图工具的特殊语法。
无文案时删除 `【文案】` 和 `【字体与配色】`，并且提示词中不允许规定字体或文字配色。
`【图片比例】`只控制画面构图，不要求生成文件的像素宽高严格匹配；同一图号的三个 direct 必须使用相同的目标构图比例。
命中平台规范定义了固定提示词前缀时，将其逐字放在首个字段之前；平台未定义前缀时直接从首个字段开始。定稿提示词不得出现该选择过程。

每项要求只在负责该内容的字段中完整表述：输入角色在 `【产品输入】`，产品保真与修改边界在 `【修改与保持】`，空间关系在 `【画面构成】`，色块映射和权限在 `【颜色/面料】`，准确文字在 `【文案】`，非文字视觉语言在 `【风格】`，文字样式在 `【字体与配色】`。不同字段可引用同一 `Image N` 或区域名，不重复整段约束。每个 direct 的正文仍须独立完整，不以“同上”或另一版提示词代替。

```text
【图片比例】
按命中平台规范和当前图号的交付类型写入唯一最终构图比例；不保留选择说明或其他候选比例。

【画面目标】
用一句话写明交付画面、单一销售任务和核心卖点，如产品使用场景、材质细节或尺寸说明；具体承载卖点的动作与视觉元素放在【画面构成】。

【产品输入】
按当前 direct 的实际输入顺序，只列连续的 Image N、角色和用途，不写路径、查看记录或素材选择过程。实际产品输入仍只能来自 manifest 登记的目标文件。目标画面出现产品时，唯一底图写为“Image 1 = edit target，当前画面唯一可编辑产品底图”；其他实拍按实际用途标为 primary product identity 或 detail/structure，只补充身份、厚度、底面或局部结构。其他输入标明 target color authority 或 insert/supporting asset；色块的具体映射写入【颜色/面料】。其他实际输入不得成为第二张可编辑产品底图。
定制产品注明承载已锁定系带数量与位置、滚边数量等结构基准的实拍图编号；仅在已确认的定制项确需补充时加入对应结构素材，具体保持要求写入【修改与保持】。目标画面不出现产品时不设置 edit target；没有实际输入时删除本字段。

【修改与保持】
目标画面出现产品时，用实际输入编号明确：将 Image 1 中的产品置入目标画面，不重新设计或替换；保持实拍中的产品身份、结构、纹理、光泽、比例和细节。其他实拍只按已声明的角色补充对应属性，不替换目标产品。不得以类别常识或主观视觉判断重述产品细节；除非用户、需求表文字或已声明的结构标注素材明确给出，形状、轮廓、截面和厚薄关系不得被命名、推断或重述，手持、按压、弯折、斜放和透视只表示姿态。
逐项写明当前方案实际需要的变化，如背景、摆放位置、产品姿态、与场景匹配的光照、依据【颜色/面料】执行的颜色校正或改色，以及已确认的定制项及范围；定制项以冻结的结构基准为依据，只改变明确允许的属性，其他属性保持实拍。场景置入不使用“其他一切不变”锁住原照片背景、人物或光线，也不允许借姿态或光照调整改变产品结构、纹理与光泽特征。
将本图适用的尺寸、人物替换、载体适配、坐垫厚度和定制结构保持约束完整写入此字段，不再在末尾追加。真实尺寸仅用于比例校验；需要显式标注时，按尺寸图规则将准确标注同时列入【文案】，其位置与尺寸线关系写入【画面构成】。目标画面不出现产品时，仅保留实际适用的保持或展示边界；没有适用项时删除本字段。

【画面构成】
写明版式结构、主体产品位置与占比、场景、背景、道具、文字区域、辅助模块和信息层级；明确承载核心卖点的场景、使用动作、产品状态、道具关系、对比或真实细节等非文字视觉元素，使画面能表达销售任务。文案、Icon 和文字标签不得作为卖点的唯一表达载体，必须配合视觉元素。不得保留未分配用途的大面积空区。
除了SKU、明确要求或内部反推确定为白底构图的情况，不要直接在版式/白底上放产品图，产品要与场景结合。`N PC` 商品写明每个使用场景中的准确产品数量；多场景画面逐区绑定场景、产品、件数和颜色映射中的区域名，每个 direct 同画面保留所有要求的场景。
有人物时明确身体取景范围、与产品的相对尺度、使用姿态及接触部位；视线影响动作表达时写明视线方向，不只写“自然使用产品”。只描述当前方案所需动作，不新增未经核实的承重、回弹或功效表现。无文案图在本字段按平台要求明确画面无文字；有文案时仅定义文字区域，具体文字与逐条位置绑定放在【文案】。

【颜色/面料】
逐项指定各色块的 Image N 及对应的画面区域、产品/部位最终颜色或色块展示用途。无论是否改色，最终产品颜色只以已声明的对应色块为准，不引用未传入的原色色块。色块只控制颜色，不改变面料、纹理、光泽、结构、比例、细节或文字视觉基准；不得用色块重构产品。未要求展示色块时，明确色块不出现在成图中；明确要求展示时，仅将指定色块作为可见元素，其位置写入【画面构成】，颜色名字或编号仅按本图适用规则列入【文案】。

【文案】
逐字写入主 Agent 按冻结语言确定的全部新增可见文字，包括标题、副标题、卖点小标题及对应正文、Icon 下方正文，以及适用的尺寸标注或颜色标签。每条按“层级/用途：\"准确文字\"；位置：已定义区域内的具体位置；出现次数：明确次数”编写；默认每条一次，明确要求重复时写出次数与各位置。主标题仍须搭配副标题，卖点小标题仍须搭配简短正文。保留冻结的大小写、标点、数字和单位；不让生图工具自行拟写、补全或翻译，不混入其他语言。明确“仅生成清单列出的新增文字，不添加其他文字”；产品原有标签或 Logo 按已确认的产品保真与品牌资产规则处理，不能借此清除或改写。

【风格】
具体写明当前 direct 所采用的视觉风格、色调与色彩、图形语言，保留整套视觉语言基准的核心特征，并可结合当前场景和构图调整措辞与细节；不得只写“与整套统一”，不得写入平台、图片比例、产品规格。要求摄影效果时明确写实摄影，并按当前方案写明光源方向、软硬、色温倾向及接触阴影、反射与环境的关系，不用“高级感”“专业打光”等词代替可见要求。纹理与光泽的具体表现必须有实拍依据，不新增材质细节。整套图不统一背景、场景或版式结构。

【字体与配色】
仅含文案时使用。写明当前 direct 所采用的文字视觉基准，包括字体家族、主标题/副标题/正文的大小层级与字重、各层级颜色（名称与 HEX 值）、描边和投影规则；保持整套的核心字体、层级和配色关系，但可为背景对比度做必要的局部适配，不得只写“与整套统一”，也不得仅因产品色块或产品颜色而重新设计整套文字风格。不重复产品布局、区域占比或文案内容。
```

`【view_image 实际输入记录】` 移至冻结任务包的内部记录：按当前 direct 的连续编号登记实际输入的绝对路径、角色、用途、来源和已完成的查看情况，不沿用其他 direct 的编号。主 Agent 记录其已完成的检查，生成 Subagent 仍须在自己的上下文查看全部实际输入并另记执行结果；记录不写入提示词文件，也不拼入工具的 prompt。工具输入路径与参数只从冻结调用合同取得。

`【内部参考反推记录】` 由主 Agent 独立保留，不属于上述提示词。每张反推专用参考图记录绝对路径、分析角色、提取的版式/场景/展示数量、卖点意图及其视觉元素、现成文案和标题/副标题信息层级，并记录支持该卖点的需求表、用户确认或已核实产品事实来源，以及商品规格的真实来源；不得写入提示词文件或传给生成 Subagent 和生图工具。

## 额外添加的提示词

本节按条件补齐字段，不在定稿正文末尾另加一组提示词。人物替换、真实尺寸、载体适配、坐垫厚度及产品展示边界归入 `【修改与保持】`；人物动作、区域关系和画面利用归入 `【画面构成】`；摄影与光线归入 `【风格】`。提示词里的 `[]` 是编写变量，主 Agent 根据已核实资料和当前方案替换后再冻结，不能让生成 Subagent 补全。与字段中已有约束合并时保留完整含义，不重复附加原段。

- 当前 direct 的目标画面需要人物时，一律加入以下提示词，不判断实拍人物是否适合沿用。`[人物要求]` 使用用户或需求表明确的人种要求；未指定时写为“符合目标市场受众的人物”，目标市场缺失时先确认。目标画面无需人物时不加入，也不额外说明移除人物。

    ``` prompt
    不得沿用实拍中的人物；重新生成[人物要求]。
    ```

    在 `【画面构成】` 另写具体动作、身体取景、接触部位及与产品的相对尺度，不能只写“正在自然使用产品”；产品本身及真实比例的保持项统一由 `【修改与保持】` 承载。

- 当前 direct 的目标画面出现非定制产品时，将 `[产品尺寸]` 替换为需求表或用户确认的真实产品尺寸并加入提示词；尺寸来源缺失时阻塞，不得猜测：

    ``` prompt
    产品真实尺寸为[产品尺寸]，仅用于理解产品在现实中的大小，并校验产品与人物、载体和场景的比例。除尺寸图外，不得在成图中以文字、数字、尺寸线或尺寸标注显式展示产品尺寸；尺寸图按已确认的真实尺寸正常标注。
    ```

- 当图中有产品出现在场景里时，在 `【风格】` 按当前场景写出以下具体关系，在 `【画面构成】` 交代有用途的生活道具与布景；不固定光源方向、时间或房间类型：

    ``` prompt
    写实电商场景摄影。[当前场景光源的位置与方向]形成[软硬与色温倾向]的光线；产品接触处的阴影、投影方向与周围环境一致，透视与载体及场景匹配，反射自然融入环境。
    ```

    例如，已规划窗边场景时可写“柔和日光从画面左侧窗户照入，产品与承载面接触处形成自然阴影，投影方向与家具一致”。这只是具体化示例，不把左侧窗光变成默认。产品纹理与光泽保持项已在 `【修改与保持】` 写明，不在本段重复。

- 当图中有坐垫之类的产品出现在应该符合尺寸载体上时，加入以下提示词，将 `[载体]` 替换为实际的载体名字。连续可定制尺寸只使用下述非数字几何关系，不自动选择或虚构具体尺寸；非尺寸图不得显示尺寸数字：

    ``` prompt
    保持产品实拍中的结构、长宽比例和厚薄关系，不得为适配[载体]而缩放、拉伸或改变产品比例；根据产品生成与其匹配的[载体]。产品沿长宽完全覆盖[载体]的可用承载面，四边分别对齐，四周不得露出任何空余承载面。
    ```

    - 包括但不限于的情况：
    - 应用情况：长凳垫/九针垫 放在 沙发/飘窗/长凳/长椅 上时
    - 排除情况: 沙发 放在 地面上, 桌布 放在 桌子上, 产品 为 靠背。

- 当坐垫产品需要放在沙发或原本已有坐垫的载体上时，加入以下提示词：

    ``` prompt
    产品(产品的名字)替代[载体]原有的坐垫，产品下方不允许出现[载体]自带的坐垫。
    ```

    - 包括但不限于的情况：
    - 应用情况：长凳垫/九针垫 放在 沙发 上时
    - 排除情况: 沙发 放在 地面上, 桌布 放在 桌子上，坐垫放在一般情况下没有坐垫的载体上(飘窗/长凳/长椅)。

- 当坐垫产品不支持异型定制，但是需要放在飘窗上时，加入以下提示词：

    ``` prompt
    飘窗的可用承载面尺寸和轮廓必须与已确认的产品匹配，保持产品实拍中的轮廓，不为适配飘窗新增异型。
    ```

- 当前 direct 出现坐垫或包含坐垫（长凳垫、九针垫、包含坐垫的套装及其他坐垫）时，在 `【修改与保持】` 写明坐垫厚度必须一致；厚度不允许定制时，用下句合并表达，不再另加一条厚度句。`[Image N]` 使用该 direct 唯一产品底图的编号；明确允许厚度定制时只按已冻结的定制项与范围处理，不自行选值：

    ``` prompt
    坐垫厚度保持一致，且必须与[Image N]中的产品厚度一致。
    ```

- 当前 direct 的目标画面出现产品时，预检 `【产品输入】` 中唯一产品底图、`【修改与保持】` 中产品保真和允许变化、`【颜色/面料】` 中最终颜色依据与色块显示边界均已完整表达。其他实际输入只承担已声明的补充角色；不再追加重复的 edit target、产品保真或色块段落。

- 当生成非纯场景副图或白底图/SKU 时，在 `【画面构成】` 写明产品占据的主要区域、各辅助模块的用途及视觉路径，保持布局丰富协调，不允许大面积留白。白底图/SKU 用完整产品的合理占比组织画面；非纯场景副图用有依据的场景、真实细节或信息模块组织画面，不为填满空间新增文案、道具或商品事实。白底、无文字等平台要求优先。

- 当商品经用户、需求表或产品实拍确认是平板海绵，且当前画面因用户、需求表、已冻结的反推结果明确要求，或因设计原则中的海绵纯场景默认分支，需要展示不直接露出海绵的填充坐垫使用效果时，加入以下提示词；异型、波浪形或其他非平板海绵，以及直接展示裸露海绵的画面，不适用：

    ```
    场景中的填充坐垫保持平直，顶部平整、边角利落，不出现鼓包、蓬松凸起、滚边、绗缝或装饰缝线；尺寸和形状与载体贴合。该坐垫只用于表达平板海绵填充后的使用效果，不改变海绵的真实结构，也不得暗示坐垫套或成品坐垫属于售卖内容。
    ```

## 通用内容图型规则

- 如果场景图展示多个场景，并且产品有多种颜色的情况下，场景图中应展示不同颜色的产品。
- 命中平台支持的任一交付类型均可按需求包含场景图、卖点文案、结构说明、尺寸说明、材质细节、定制选项、使用前后对比、颜色选择、SKU 展示或规格展示；副图的信息可以比主图更完整。
- 颜色、图案、尺寸、数量或定制选项必须准确，避免误解实际可选范围和售卖内容。
- 尺寸图必须结合真实产品尺寸和常见参照物，避免把产品做得过大或过小。
