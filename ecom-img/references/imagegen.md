# imagegen 适配器

选择 `$imagegen` 时，先完整读取其 skill，只使用内置 `image_gen` 工具；不要调用 `scripts/image_gen.py`、CLI/API 回退模式或要求 `OPENAI_API_KEY`。其 skill 只提供工具调用指导，不采用其中扩写提示词、验图或迭代选片的步骤；冻结提示词与生成结果边界按 [生成模块](generation-workflow.md) 执行。本适配器只补充调用合同、来源追踪、保存和恢复差异。

## 调用与来源

- 按生成模块为每个 direct 派发一个全新单版生成 Subagent；该 Subagent 只允许调用一次内置 `image_gen`。
- 硬性调用合同须逐项列出按 `Image N` 顺序冻结的 `referenced_image_paths`；所有输入必须有本地路径并由此显式传入，不得依赖“最近图片”或其他 direct 的会话上下文。调用前确认路径不超过 5 条。这是现行项目限制；当前未核实它是内置工具的通用路径上限，不自行放宽。
- 输入超过 5 条时，由主 Agent 在派发前把同一角色的非实拍辅助素材（如多个色块）整理为已查看的拼版，并在【颜色/面料】按拼版内位置写明映射；产品实拍必须保持 manifest 登记路径，不参与拼版。整理后仍超过 5 条时阻塞当前 direct，不得用一次失败调用探测上限。
- `referenced_image_paths` 中的产品实拍只允许使用 `2560px拍摄图/_manifest.json` 登记的目标路径；禁止使用原始拍摄图。当前任务中已执行 `view_image` 并记录角色的颜色/面料、结构细节、插入或辅助素材可以作为其他实际生成输入。反推专用参考图禁止加入 `referenced_image_paths`。
- 禁止使用 `num_last_images_to_include`；任何输入缺少本地路径时阻塞当前 direct，取得准确路径并重新执行 `view_image` 后再生成。
- 禁止把其他 direct 作为输入、参考图或上下文；技术失败先按生成模块区分恢复保存与生成替补，下文只补充源路径缺失时的独占恢复方式。
- `$CODEX_HOME/generated_images` 是全局生成目录，可能混入其他 Session、产品、平台或语言的图片；禁止按“最新时间”“最新文件”或“最大文件”猜测复制。
- 每次调用前记录任务 ID、平台、产品名、图号、direct、目标文件名、提示词编号和调用开始时间，并对全局生成目录建立文件快照。
- 并行调用只接受当前工具为本次调用返回的明确源文件路径；不得通过完成时间、文件名、排除其他调用文件或跨调用快照差异认领来源。没有明确源路径时，生成 Subagent 只返回“源路径缺失”的调用记录，不得自行标记 direct 终态或关闭自身；主 Agent 在源文件检查失败后记录 `TECHNICAL_REJECT` 并按生成模块处理该 Subagent 生命周期。
- 并行结果缺少明确源路径时，等待当前图号的初始批次全部结束且相关 Subagent 已按生成模块清理，再由一个全新替补 Subagent 独占重试该 direct；只有这次独占调用允许使用调用前后快照差异定位，且候选必须唯一，恢复期间不得派发其他生图调用。
- 结果不唯一、路径不明、时间异常、尺寸无法读取或不合法，或来源记录与当前任务、图号、direct 不一致时，判定为技术失败，不得作为有效 direct 保存；原生宽高比偏离目标构图比例不属于技术失败，不因此重生。
- 每次调用只接受可唯一归属的一张源图。

## 保存与清单

- 所有 ImageGen 生成 Subagent，包括独占替补，只向主 Agent 返回当前调用的明确源文件路径和完整来源记录，不得自行复制文件或写入共享清单。
- 主 Agent 按返回结果逐张串行执行固定顺序：`源文件检查 -> 主 Agent 串行复制 -> 目标文件检查与记录 -> 标记 direct 终态 -> 按生成模块处理 Subagent 生命周期`。源文件检查只核对明确路径、可读取性、尺寸、源 SHA256 和调用记录的唯一归属；通过后复制到 `./output/gpt-images-2-direct`，再核对目标文件可读取性、尺寸、目标 SHA256 及源/目标哈希一致性，记录复制时间、提示词编号和保存确认结果。全部通过才标记 `SAVED`；失败时按生成模块判断恢复或技术失败，完成记录后按同一生命周期规则处理，有关闭接口才关闭，没有则以执行结束为准。
- 主 Agent 是 `./output/gpt-images-2-direct/_imagegen_manifest.jsonl` 共享清单的唯一写入者；每张有效 direct 的目标检查通过后逐行串行写入，生成 Subagent 不得写入。
- 技术失败文件如已复制，移入 `./output/temp/rejected-imagegen` 或在清单中标记为 `TECHNICAL_REJECT`，不得作为有效 direct 保存。

## 中断恢复

- 每生成一张就立即保存到直接生成目录，不等三版全部完成。
- 调用或 Session 中断、超时或未稳定进入下一次生成时，核对直接生成目录的文件数量、大小和时间戳。
- 结合调用记录，从缺失图型与 `direct` 序号按生成模块恢复保存或执行允许的技术替补；未补齐且未记录最终 `TECHNICAL_REJECT` 前不得标记完成。
