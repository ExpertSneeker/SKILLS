# 平台注册与判定

| platform_id | 平台名称与别名 | 唯一规范 |
| --- | --- | --- |
| amazon | Amazon、amazon、亚马逊 | [amazon.md](amazon.md) |
| temu | TEMU、Temu、temu | [temu.md](temu.md) |

- 平台只取用户明确指定值或需求表的平台字段；用户明确覆盖旧平台字段时采用该更新，其他字段按新平台强制要求校验后沿用。仍有未解决歧义、缺失或平台不支持时不猜测平台。
- 竞品链接、目录名、语言、图片比例、A+、输出目录及历史任务不是平台字段。
- 生成模式在查看产品实拍或表内图片、制定平台方案前确定唯一平台；可先读需求表文字。仅规划模式在平台未定时只输出平台无关草案与待确认项，不加载候选平台或生成可执行合同。
- 平台确定后只读取唯一命中规范，不读取、混合或借用另一个平台规则。命中平台的专项规则优先于通用设计与提示词模板默认；平台强制要求不能被用户视觉偏好或参考图覆盖，未解决的品牌硬约束仍需处理。
- 同一任务所有图号及其三版使用同一平台规范；同一产品需要两个平台时分别组织两套任务。
- 交付类型（主图、副图、A+、详情页等）与默认构图比例只由命中平台规范提供。场景图、尺寸图、卖点图、颜色图、SKU 图、规格图等内容图型可出现在任一受支持的交付类型中；两者分别按用户或需求表确认，不得仅凭内容图型改判交付类型。
