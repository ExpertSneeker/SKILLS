# 产品与场景规则

按当前画面选读下列适用章节；未核实资料不能被草案中的设计选择替代。

本节按条件补齐字段，不在定稿正文末尾另加一组提示词。人物替换、真实尺寸、载体适配、坐垫厚度及产品展示边界归入 `【修改与保持】`；人物动作、区域关系和画面利用归入 `【画面构成】`；摄影、光线与人物肤质归入 `【风格】`。提示词里的 `[]` 是编写变量，主 Agent 根据已核实资料和当前方案替换后再冻结，不能让生成 Subagent 补全。与字段中已有约束合并时保留完整含义，不重复附加原段。

## 人物

- 当前 direct 的目标画面需要人物时，一律加入以下提示词，不判断实拍人物是否适合沿用。`[人物要求]` 使用用户或需求表明确的人种要求；未指定时使用命中平台规范规定的人物，平台也未规定时写为“符合目标市场受众的人物”，目标市场按需求表或命中平台的默认站点确定。`[人物外貌]` 使用下方冻结的人物外貌基准。目标画面无需人物时不加入，也不额外说明移除人物。

    ``` prompt
    不得沿用实拍中的人物；重新生成[人物要求]：[人物外貌]。
    ```

    在 `【画面构成】` 另写具体动作、身体取景、接触部位及与产品的相对尺度，不能只写“正在自然使用产品”；产品本身及真实比例的保持项统一由 `【修改与保持】` 承载。

- 人物外貌基准：主 Agent 在编写首个含人物图号的提示词前，按 `[人物要求]` 冻结一段 80–150 字的外貌描述，写明脸型与骨相、眼型与虹膜颜色、眉形、鼻型、唇形与原生唇色、下巴、肤色、发色与发型及大致年龄；不取自实拍或参考图中的人物，用户或需求表给出人物外貌时以其为准。整套图统一一个人物：所有出现该人物的图号和 direct 逐字复用同一段描述；需求表要求多个人物时，每个角色各冻结一段，并在整套中各自复用。生成模式将其随任务记录保存到 `./output/`，仅规划时写入方案。人物只露出手、腿等身体局部而不露出面部时，`[人物外貌]` 只保留肤色等可见部位的描述，不写五官。

- 当前 direct 的目标画面需要人物时，在 `【风格】` 加入以下肤质提示词；画面不出现人物时不加入，也不写“无人物”之类的说明。人物只露出手、腿等身体局部而不露出面部时，只加入第一句。

    ``` prompt
    人物皮肤为自然哑光质感，保留细微毛孔和自然肤色变化。
    面部妆容清淡，受光柔和均匀，高光只小而柔地出现在额头、鼻梁等处，不出现大面积油亮或湿润反光。
    ```

- 描述人物（含人物外貌基准）时只写可见特征，不使用“美丽”“精致”“完美肌肤”“光滑”“水润”等评价词或容易诱导出油光的词。

## 真实尺寸

- 当前 direct 的目标画面出现非定制产品时，将 `[产品尺寸]` 替换为需求表或用户确认的真实产品尺寸并加入提示词；尺寸来源缺失时阻塞，不得猜测：

    ``` prompt
    产品真实尺寸为[产品尺寸]，仅用于理解产品在现实中的大小，并校验产品与人物、载体和场景的比例。除尺寸图外，不得在成图中以文字、数字、尺寸线或尺寸标注显式展示产品尺寸；尺寸图按已确认的真实尺寸正常标注。
    先按真实尺寸确定产品与人物、载体及场景的相对尺度，再通过镜头距离和构图安排占幅；不得为满足占幅或使用姿态放大产品、缩小人物或参照物。发生冲突时调整取景或姿态，真实尺度优先。
    ```

## 场景摄影

- 当图中有产品出现在场景里时，在 `【风格】` 按当前场景写出以下具体关系，在 `【画面构成】` 交代有用途的生活道具与布景；不固定光源方向、时间或房间类型。`[场景摄影类型]` 默认写为“写实电商场景摄影”，命中平台规范另有写法时按平台规范及其适用条件：

    ``` prompt
    [场景摄影类型]。[当前场景光源的位置与方向]形成[软硬与色温倾向]的光线；产品接触处的阴影、投影方向与周围环境一致，透视与载体及场景匹配，产品表面的反射自然融入环境。
    ```

    例如，已规划窗边场景时可写“柔和日光从画面左侧窗户照入，产品与承载面接触处形成自然阴影，投影方向与家具一致”。这只是具体化示例，不把左侧窗光变成默认。产品纹理与光泽保持项已在 `【修改与保持】` 写明，不在本段重复。

## 坐垫与载体

- 当图中有坐垫之类的产品出现在应该符合尺寸载体上时，加入以下提示词，将 `[载体]` 替换为实际的载体名字。连续可定制尺寸只使用下述非数字几何关系，不自动选择或虚构具体尺寸；非尺寸图不得显示尺寸数字：

    ``` prompt
    保持产品实拍中的结构、长宽比例和厚薄关系，不得为适配[载体]而缩放、拉伸或改变产品比例；根据产品生成与其匹配的[载体]。产品沿长宽完全覆盖[载体]的可用承载面，四边分别对齐，四周不得露出任何空余承载面。
    ```

    - 适用（包括但不限于）：长凳垫/九针垫放在沙发/飘窗/长凳/长椅上。
    - 不适用：沙发放在地面上、桌布放在桌子上、产品为靠背。

- 当坐垫产品需要放在沙发或原本已有坐垫的载体上时，加入以下提示词：

    ``` prompt
    产品(产品的名字)替代[载体]原有的坐垫，产品下方不允许出现[载体]自带的坐垫。
    ```

    - 适用（包括但不限于）：长凳垫/九针垫放在沙发上。
    - 不适用：沙发放在地面上、桌布放在桌子上、坐垫放在通常没有坐垫的载体（飘窗/长凳/长椅）上。

- 当坐垫产品不支持异型定制，但是需要放在飘窗上时，加入以下提示词：

    ``` prompt
    飘窗的可用承载面尺寸和轮廓必须与已确认的产品匹配，保持产品实拍中的轮廓，不为适配飘窗新增异型。
    ```

- 当前 direct 出现坐垫或包含坐垫（长凳垫、九针垫、包含坐垫的套装及其他坐垫）时，在 `【修改与保持】` 写明坐垫厚度保持一致。厚度不允许定制时使用下句，`[Image N]` 为该 direct 的 edit target 编号；明确允许厚度定制时只按已冻结的定制项与范围表达，不自行选值：

    ``` prompt
    坐垫厚度保持一致，且必须与[Image N]中的产品厚度一致。
    ```


## 平板海绵使用效果

- 当商品经用户、需求表或产品实拍确认是平板海绵，且当前画面因用户、需求表、已冻结的反推结果明确要求，或因 [海绵纯场景默认分支](design-and-prompt.md#海绵纯场景默认分支)，需要展示不直接露出海绵的填充坐垫使用效果时，加入以下提示词；异型、波浪形或其他非平板海绵，以及直接展示裸露海绵的画面，不适用：

    ``` prompt
    场景中的填充坐垫保持平直，顶部平整、边角利落，不出现鼓包、蓬松凸起、滚边、绗缝或装饰缝线；尺寸和形状与载体贴合。该坐垫只用于表达平板海绵填充后的使用效果，不改变海绵的真实结构，也不得暗示坐垫套或成品坐垫属于售卖内容。
    ```
