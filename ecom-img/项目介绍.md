# 电商商品图 AI 辅助设计工作流

> 把产品资料、设计经验和业务要求，整理成 AI 可以重复执行的商品图制作流程。

**适用业务：** Amazon / TEMU 商品图制作。

## 核心功能一览

| 核心功能 | 简要介绍 |
| --- | --- |
| **需求整理** | 结合需求表、产品实拍、尺寸与色块，明确制作内容和要求。 |
| **方案规划** | 规划使用场景、卖点展示、画面布局与文案。 |
| **产品约束** | 以实拍、尺寸和色块为依据，约束产品结构、材质、比例与颜色。 |
| **风格统一** | 为整套图片设定统一的字体、配色和视觉规范。 |
| **多版生成** | 按计划为每个图号生成三张独立设计版本，供设计人员选择。 |
| **交付管理** | 按任务整理文件、记录执行状态，支持中断后的恢复处理。 |

## 项目价值

**目标：减少重复操作，沉淀设计经验，让商品图制作流程可复用。**

## 人机分工

**AI 辅助规划与生成；设计人员负责最终选图、内容审核和发布把关。**

本项目搭建业务规则与工具衔接，调用已有 AI 模型，不研发底层模型；不执行生成结果的自动视觉验收，也不承诺未经实测的效率提升幅度。
