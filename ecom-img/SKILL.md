# 电商商品图片

## 任务路由

先确认任务根目录与本次交付目标。任务类型按用户要求判定为仅规划、生成或恢复，不由是否处于 Plan mode 决定。

- **仅规划／编写提示词**：用已有且获准读取的信息交付方案或提示词草案，标明待补事实和受影响图号。不调用生图、不自动初始化，不创建或修改 DESIGN、manifest、缓存、调用记录等生产状态文件。缺少 manifest 时只依据需求文字作有限规划，不读取原图，也不以未登记图片替代产品实拍。草案不得作为可执行的冻结任务包。
- **生成**：在任务根目录工作，记录进入生成模式时 `./DESIGN.md` 是否存在。满足生成门禁并完成设计与冻结后，按生成模块连续执行所有计划图号，不在第一版或某个图号结束时停下等待确认。
- **恢复**：先读已有调用记录和当前工具适配器，只执行记录允许的保存、下载或技术替补；文件缺失不等于可以重新生成。仅恢复保存时不重做设计、不重建 DESIGN、不重跑素材检查；执行技术替补时仍须满足生成门禁并使用原冻结任务包。

## 全局边界

- 产品实拍只使用 `2560px拍摄图/_manifest.json` 登记的目标文件；原图及 `source_*` 不进入任何 Agent、输出或生图输入，拒绝路径越界及链接逃逸。缺 manifest 时不自动调用初始化 Skill，须由用户明确调用 `$init-2560px-images`。
- 反推专用参考图及其内部记录只供主 Agent 规划，不传给任何 Subagent 或生图工具。
- 用户明确更新平台或视觉字段时，只更新该字段的有效任务基准，其他字段沿用；不覆盖平台强制要求、原图边界或未解决的品牌硬约束，不改写既有 DESIGN。
- 每个图号生成 direct01、direct02、direct03 三版：主 Agent 规划并冻结任务包，每版由一个全新 `product_image_creator` 执行。
- 生成后不查看结果、不挑选 FINAL、不因内容返修或修图，只做非视觉的文件、唯一来源和哈希确认；结果未知时不重新 POST，下载恢复不重新生成。

## 生成门禁与工具

生成前须具备：明确且受支持的唯一平台、需求表、真实产品尺寸（定制产品可为已确认的尺寸区间）、非空有效 manifest；各图号的交付类型、内容图型、构图比例、语言和单位已按需求与平台冻结；产品基准、实际素材分类、适用定制规则和视觉基准已完成。只检查当前任务实际使用的素材。反推参考图可缺省，产品最终颜色依据不得缺省。SKU 交付范围按设计模块确定；范围有歧义或必要颜色素材缺失时，只暂停受影响项。

每个图号首次派发前，预写完整的 direct01、direct02、direct03 任务包并按生成模块预检；未通过的 direct 不得派发。

用户指定工具时使用该工具：有对应适配器时读取适配器，否则读取该工具自身 Skill；未指定时使用 `$imagegen` 与 [ImageGen 适配器](references/imagegen.md)。`豆包`、`豆包生图`、`Seedream`、`Seedream 5.0 Pro`、`seedream5.0pro` 均使用 [Seedream 适配器](references/seedream.md)及 `scripts/seedream5_pro.py`，不得转交其他生图工具。任务内不更换工具。

仅规划时交付方案与待补项；生成／恢复按生成模块区分完整交付、部分交付、最终技术失败与结果待核实，不将“处理完”说成“全部成功”。
